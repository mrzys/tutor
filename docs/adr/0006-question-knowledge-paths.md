# ADR-0006：题目主考知识点与逐解法依赖

- 状态：已采纳，2026-10-19，依据用户对知识点粒度方案的明确同意。
- 细化 ADR-0002 的主考范围／已学边界；沿用 ADR-0005 的本机存储与内容审核边界。

## 决定

新导入的题目以正式知识点 UID 为底层标注。主考知识点与完成某条解法实际需要的知识分别保存：

| 字段 | 含义 |
| --- | --- |
| `knowledgeSchemaVersion: 2` | 新标注合同 |
| `primaryKnowledgeUids` | 本题主要考查的真实知识点 UID |
| `solutionPaths[].id` | 这条完整解法的稳定身份 |
| `solutionPaths[].requiredKnowledgeUids` | 这条解法所需知识点，包含本题主考知识点 |
| `solutionPaths[].requiredPremises` | 额外工具／前提，保持独立 |
| `solutionPaths[].basis` | 能完成整题及所有小问的解法与依赖依据 |

知识点由模型选择后直接关联生效，题目内容仍须审核。没有解析依据时不虚构原文解答；
未标注主考或缺完整路径的题可保留手动使用，但自动适配保持未知。
不同解法的依赖不能合并为一个必须同时满足的集合，至少一条完整路径符合已学边界即可。
未知 UID、错误类型和路径身份冲突拒绝保存，不将无效新版字段降级为章节适配。

题目知识点映射按 `primary`、`supporting` 保存角色，支撑关联同时保存 `solutionPathId`。
新版知识点题数及知识点筛选默认只统计主考，不能因某知识点出现在解法中就算该知识点专项题。
这些标注是模型／教师编辑的内容判断，不能当作独立教学有效性或真实学生掌握证据。

## 章节与知识图谱

教材小节继续作为导航和教师选择范围的入口，通过已有 UID—教材映射投影。
没有显式知识点范围时，以已有教材映射检查知识点是否落入所选小节；
显式 `mainKnowledgeUids`／`learnedKnowledgeUids` 优先，允许用知识树分组选择其后代，
但不能把同小节中的其它知识点自动视为已学。宽泛分组的后代小节投影仅用于导航，
不凭某个小节命中就认定整个分组适配。

`knowledge_relations` 中一般性的前置／相关关系分别保留，不递归生成本题主考或解法依赖。
`primarySections`／`requiredSections` 为新版的教材兼容投影，不再作为新版自动适配的依据。

## 持久化与兼容

组卷索引继续位于 `question-bank.sqlite` 的 `bank_metadata.config.assemblyIndex.entries`，
通过 `questionId`、`contentVersion`、`teacherVersion` 绑定题目版本。
带角色的映射保存在本地题库映射记录中；不同解法使用同一支撑 UID 时各自保留路径身份。
读取时构造 `knowledgeCatalogue` 供 UID 验证和教材投影，不改写原始共享档案。
草稿适配结果保存本次主考 UID、允许解法及依赖，成卷沿用冻结快照。

旧题没有新字段时继续采用原有章节标注，不把已有泛化知识点关联解释成主考或完整解法依赖。
本次不批量调用模型重标旧题，不重写原库、成卷和题目内容；查看、刷新、预览不调用模型。
旧导入记录保持可读、可继续审核，新模型请求使用新合同。

## 2026-10-20 显式重标授权补充

用户随后明确要求对现有题目同时重标难度、主考知识点和逐解法依赖；上面的“不批量重标”仅描述 2026-10-19 初次迁移范围，不限制这次明确授权的维护任务。重标通过版本与旧标注哈希检查更新有效组卷索引，原始关联台账、来源、数学审核范围和冻结成果保留；刷新与历史读取仍不触发模型。

新模型标注只选择真实叶知识点，目录父节点用于上下文与范围导航，不能替代具体考点或自动展开猜测依赖。旧宽泛关联继续可读，按原有保守边界判断适配。依据不足时保留未知，不能用“需补证明”的待办描述冒充完整解法；明确纠错意见也须由模型核对原文，不成为新的原文证据。

模型重标结果以独立元数据清单分发，事务验证题目版本及原标注哈希，本地冲突整批回滚，不覆盖教师修改；不改写原始种子迁移身份或审核状态。

旧共享题库按整卷补充沿用导入审核边界。已结构化的题面直接携带原 PDF、完整原卷条目与哈希绑定素材，不让模型再转录；每次显式调用只补一批元数据。旧库生成或人工参考保留独立来源，不能自动填入原卷答案／解析，也不能作为独立数学核验。所有题目准备后保持待审核，缺图等来源问题仍阻止入库。原题重复不自动丢弃整卷条目，发布前再次核对现有题库。
