# ADR-0011：导入合并为处理与复核两个模型

- 日期：2026-11-03。
- 状态：已采纳；用户明确要求减少逐题六次调用，合并流程，使用 DS Flash 处理、阿里云百炼 Qwen 复核，普通设置只配置两个模型。
- 本决策调整 [ADR-0010](0010-import-accuracy-first.md) 的中间策略及独立盲解要求，保留 OCR 输入、最终题目与教学字段合同、实际核对依据、显式修订、预算及教师发布边界。

## 问题与决定

原准确性策略在识别、来源索引和转录之后，每题依次调用来源核验、解答生成、独立求解、数学核验、教学字段生成和教学核验。六个逐题请求带来过多调用和配置负担。

新上传使用 `import-two-model-v1` 策略，来源转录后只执行两次模型请求：

1. **处理**：DS Flash 在同一次响应中返回解答候选与教学字段候选，包含答案、完整解析、主考知识、解法依赖、难度及依据、考查点和学生要求。原题、原参考和真实目录仍是只读输入；生成稿不覆盖原参考，不把生成自评当作核验通过。
2. **复核**：Qwen 在一次请求中对照实际原页、原题、原参考、上述候选和目录，分别返回来源、数学、教学三个域的逐项核对报告和具体依据。核验不直接改稿；任何必要目标缺失、实质问题或未判继续待处理，不因另一个域通过而自动放行。

新策略取消额外独立盲解。Qwen 会看到 DS 候选，不把这次复核称为“隔离求解”或“独立盲解”，也不把模型同意当作独立人工真值。此处明确取代 ADR-0010 对这类新任务要求先封存盲解再比较的执行要求；旧任务仍沿其原策略解释。

教学字段与解答在同一次处理响应中形成，均是待复核候选。最终仍由程序按照版本化合同组合，不伪造另一份模型完整响应，不借用人工修订身份；每个投影字段可回到同一真实请求和响应的确切位置。三个复核域同样引用同一个真实复核响应，不伪装成三次调用或三个独立核验者。

## 配置和运行边界

- 普通设置只展示“处理模型”和“复核模型”，各自选择已保存的命名配置和已确认支持的思考设置。按用户要求推荐 DS Flash 和百炼 Qwen，实际请求使用用户显式保存的服务商、型号及独立密钥，不按名称自动切换或迁移。
- 显式选择处理模型时，同时绑定现有 `sourceParsing` 和 `teachingGeneration`；两者使用同一命名配置，仍允许保留原有的拆题与内容处理思考差异。复核绑定现有 `teachingReview`，也用于用户明确发起的有界修订。
- 旧四项核验用途放在默认折叠的高级设置中，供旧任务继续使用。只读打开、切页和升级不改写原配置；旧拆题与生成配置不一致时，要求用户明确选择统一的处理模型并保存。
- 原来源索引、分批转录及其断点仍单独执行。OCR、来源调用、失败后的显式重试和问题修订不计入“每题两次”的正常后处理数量；不得声称整卷只有两个请求。
- 对照原页仍需已确认的图片能力和真实可读的材料，不用 OCR 与转录相互一致冒充已看原图。读取历史不外呼。
- 失败不自动换模型、循环复核或增加重试。修订由用户明确发起，保留原稿、具体问题和已用额度，修后重新核验受影响版本，不能由修订模型自评授予发布资格。
- 新策略冻结实际模型绑定、提示词、响应合同、预算、来源和候选版本。成功请求仅在精确输入仍一致时复用；未成功或格式不完整的响应不补造为有效证据。
- 旧六步运行继续自己的冻结策略；“继续”不自动切换到两段流程、不重置额度、不重跑历史、不改写既有题库或成卷。本次不提供静默迁移旧运行的入口。

## 调用量和验证口径

正常首次完成 N 道题的后处理，从 `6*N` 减为 `2*N`。20 题对应 120 次降为 40 次后处理请求，另外计算真实 OCR、索引和来源批次。缓存、失败、材料问题、人工核对及显式修订会改变实际请求数；次数减少不代表已证明准确率、耗时或成本的固定改善幅度。

隔离工程回归须验证实际请求次序与次数、逐域阻断、响应重放、缓存、修订预算、旧策略继续以及设置保存和撤销。工程模拟不能替代真实模型准确率评测；当前不声称两段策略与原六步策略有相同错误检出率。
