# ADR-0010：试卷导入以最终内容与教学信息准确性为先

- 日期：2026-11-02。
- 状态：已采纳，2026-11-02；用户明确同意 D1、D2、D3，并确认“两头不变，中间可以变”。本工作区已接入实现，并完成隔离工程回归及[单卷真实服务试导入](../validation/import-accuracy-first-real-paper-2026-11-02.md)；该卷 21 题中 2 题可确认、19 题待处理，40 题独立复审试点未完成，未取得真实模型准确率或教师使用结论。
- 详细设计：[导入准确性优先重设计](../design/import-accuracy-first-redesign.md)。
- 2026-11-03 调整：[ADR-0011](0011-two-model-import.md) 已采纳。新上传合并为一次处理与一次统一复核，取消额外独立盲解，普通设置保留两个模型。本文六步及盲解要求继续用于已绑定原策略的任务，其余准确性、最终合同、具体依据和发布边界保留。
- 本轮复审：[GLM5.3 与 Gemini 意见处理](../review/import-accuracy-first-design-review-2026-11-02.md)。采纳依据是用户随后明确同意，外部评审本身不是授权来源。

## 用户已明确的目标和约束

1. 首要目标是提高入库题目的最终内容及教学信息准确性。入库率是次要结果；低入库率但高准确性符合本次目标。
2. OCR 识别输出结构保持不变。
3. 最终题目内容结构、题目教学信息结构及已有字段含义保持不变。
4. 重新设计从上传试卷到形成上述两份成果的流程及中间数据，明确处理记录与最终成果的边界。
5. 两端合同稳定，中间策略可持续调整：OCR 是输入端，最终题目内容及教学信息共同构成落地端。阶段、候选、核验方式和过程数据不被固化成永远不变的产品合同。

## 已采纳的决策

保持现有原件、OCR、最终题目和教学标注合同，只增加独立的过程记录：来源候选、解答候选、独立求解结果、核验报告、教学信息候选、问题处置和定稿清单。新增过程定稿重放校验，通过兼容现有输出合同的适配器投影成原有最终结构，不伪造旧工作流，也不把新增审核状态、模型响应或核验细节塞入最终业务字段。

新流程对准备作为合格成果发布的每一道题，分别取得来源保真、答案与证明、教学信息的有效核验记录。新增单独求解时先封存不含生成稿及原答案的盲解结果，再比较候选、独立解与原参考；分歧保留具体依据，不能以模型投票决定数学正确性。模型核验仍是风险控制，不是独立人工真值。

先确定来源，再核查解答，然后根据固定的题面和解答形成、核对教学信息。难度、主考知识及解法依赖不能反向充当答案正确的证据。所有结论绑定实际输入和候选版本；修改使受影响的下游结论失效。

已发现实质问题或核验不足的预期发布内容继续待处理。原卷确实无答案解析与提取遗漏分别记录；未知保留现有空值表达，不为凑齐字段补造内容，也不以删掉错误字段提高合格入库率。教师仍显式确认发布，无须逐题强制勾选所有合格题。

## 相对当前执行政策的变化

本 ADR 采纳覆盖拟发布内容的核验要求，不能由现有同次自评、完整性检查或零术语命中代替。新版本策略取代“无问题命中不调用复核，命中后一次修复”的相应执行政策；只有实现并显式启用新策略的任务按新要求执行，不将文档采纳伪称为当前应用已切换。

核验和修复分开：核验不改稿；发现问题后显式发起有界修订，再核验新版本。初始策略沿用一次修订预算，保留后台持久化、来源预算与 worker 约束、成功断点、原稿和已用额度、显式重试、不自动循环、不隐式换模型、最终教师确认的边界。新增任务有明确用途配置及调用预算，不继承其他用途的凭据或猜测图像能力。

### 两端固定，中间策略演进

OCR 输入合同与最终落地合同各自独立于处理策略；策略改版不要求改 OCR 字段、题目内容、教学信息结构或既有渲染/组卷读取合同。当前详细设计中的阶段数、任务拆合、候选实体、核验实现、并发与预算参数是初始方案，允许按证据演进。

中间层使用独立 `strategyVersion/strategySha256`，封存实际阶段图、提示词、角色绑定、过程 schema、组合/核验规则及预算快照。`pipelineVersion` 继续标识执行引擎/过程协议，不能代替具体策略身份。两者均位于过程记录，不向最终题目增加字段。

在已采纳的准确性、权限、隐私和费用范围内，常规策略优化通过版本、兼容检查及隔离评测推进，无需为每次拆合阶段重复发起产品采纳。若要改变两端合同、降低已确认的质量边界、增加未授权支出、自动换已保存模型或改动已冻结成果，则属于范围变更，必须明确处理。

同一运行绑定不可变策略和输入版本，恢复默认继续原策略；切换策略创建明确的新运行/修订，记录继承关系，并只复用输入及适用条件仍有效的原件、OCR、候选和证据。策略更新不自动重跑历史、重置额度、重标审核或改写题库/成卷。旧过程记录按自身版本可读取、可追溯，不要求中间 schema 永远冻结。

冻结策略允许执行其中预先定义的条件分支，根据实际材料选择路径并记录真实调用；不强迫所有题走完全相同的步骤。改变政策规则才产生新策略版本，已有策略内的分支执行不能成为隐式增加重试或突破父预算的理由。

ADR-0002“未知或缺项不取消用户确认权”描述组卷草稿及成卷交付，不直接授予有缺图/错题的题库发布豁免。D2 的依据是当前实际人工入库路径及新质量门槛的差异，不能把两个场景混为一谈。教师仍可实际裁决模型分歧；保留未判与忽略已知实质错误属于不同决定。

## 替代方案与代价

| 方案 | 可获得什么 | 主要代价及本 ADR 取舍 |
| --- | --- | --- |
| 仅加强人工抽查 | 较少模型调用，独立人工判断直接 | 未抽查题风险仍未知，人工量高；适合评测基准，不能给全体成果追加已核验标签 |
| 两模型互看解答并交叉复核 | 调用较少，便于发现部分显式错误 | 输入相互影响且错误可相关，不能用一致性当真值；不作为唯一发布依据 |
| 只抽样执行新增核验 | 降低时间和费用 | 未核验题不能获得与已核验题同等资格，可作为后续经证据验证的范围策略；首轮试点不采用抽样真值 |
| 本 ADR 的分域核验与隔离求解 | 错因和依赖明确，拟发布版本具有可追溯检查覆盖 | 调用和存储成本高，可能误阻断；以有界试点检验净收益，未证明收益不直接放量 |
| 模型复读完整七字段并逐字锁定数学稿 | 溯源直观，便于沿用原完整响应重放 | 标点/公式漂移可能拒绝合格元数据；作为 D3 的兼容对照，不预设拒绝率 |

## 成立前提与收缩条件

1. 来源核验能依据实际原页发现转录问题，模型核验对真实数学/证明错误具有可测的检出能力，而不是只增加泛泛疑点。
2. 实际发送路径能证明盲解没有收到参考答案、解答构造图或共享对话；程序组合和目录快照均可重放。
3. 固定调用/令牌/时长预算能在隔离试点执行；费用在获得真实费率和用量前保持未知，不承诺分钟级完成。
4. 教师工作量、严重漏放和正常题误阻断同时评测。若新增检查漏掉错误却增加误阻断，先冻结放量，定位并收缩无净收益的检查阶段；不能为维持架构而保留无效调用，也不能悄悄取消必需核验后仍称符合本 ADR。变更核验范围需新策略版本和明确决定。

## 验证原则

按实际原件建立独立审阅基准，发布决定与独立审阅真值分开。分别报告题面保真、答案正确、证明完整、教学信息与依据一致、危险放行、未判、技术失败、人工工作量，以及入库率。保留分母、题型和难度构成；不能用模型同意率、JSON 成功率或入库率证明准确性提升。

首轮建议固定 40 道目标题，全部独立复审，包括拟发布和待处理题；按来源和实际调用计划冻结上限，具体数字见详细设计 §7。随后放量的抽样规则另定，不将试点成本默许为无限。

当前交付包含已采纳设计与本工作区初始实现。新过程存储、用途分配、来源请求预算、独立任务请求、受限组合和发布重放分别验证；具体实施边界见详细设计文末。工程回归使用隔离数据库和本机 HTTP 模拟，不代表新流程数学正确率或真实教师使用效果；40 道真实目标题的独立复审试点尚未执行。
