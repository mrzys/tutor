## 职责变更

教学语义判断交给当前配置的 LLM：理解教师原话中的范围、题量、题型、时长和计分要求；提出题位规划；依据真实题面判断候选相关性、难度、可用解法与教学要求的匹配；整理导入内容及检查意见；依据真实题干和作答材料批改。

旧章节／主考标签、完整解法元数据和难度标注可作为模型参考，不再由固定规则替代本次教学适配判断，也不能因字段缺失先把题从模型候选中淘汰。候选来自真实且当前有效的题库版本；模型不得编造新题或扩大已确认条件。程序不把未知、未评或模型失败解释成适合；真实不足保留缺题。

取消新组卷中的“规则预设”“规则选题”及模型失败后的规则兜底。旧记录只读兼容，不重写原快照；旧模式的执行请求明确提示已停用。手动组卷篮继续表达教师已明确作出的选择，不为移除教学规则而强制插入一次模型审批。

教师尚未明确题量时，模型可以提出待确认的题量与配比，不能把隐藏的默认十题当作教师已经决定。教师明确或确认后的数量继续保持；缺少有效模型建议时保留输入并重试，不采用默认配比补造结果。新请求的缺省来源使用当前完整真实来源清单，不继承旧模板中不可见的来源子集；显式或已冻结的来源选择保持。

## 程序继续保证的数据约束

- 教师确认节点、明确题量／题型／来源／范围和分值约束不能被模型静默改变。
- 真实题目、题位、目录和素材身份及版本必须有效；重复题和失效内容不能靠模型意见放行。
- 文件归属、路径边界、哈希、素材完整性、学生与教师内容隔离保持不变。
- 草稿修订检查、操作幂等、原子提交、取消恢复和成卷不可变保持不变。
- 导入意见须来自实际材料；答卷批改保留真实题干与作答引文，缺少必要证据仍为暂无法判断。模型置信档只作说明，不由本地阈值覆盖模型判断，也不冒称独立正确率。
- 分值上限、合计及结果身份是数据校验；不以关键词、公式符号白名单或固定题型权重替代教学判断。
