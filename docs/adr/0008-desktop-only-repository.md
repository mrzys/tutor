# ADR-0008：仓库只维护桌面主应用

状态：已采纳，2026-10-21，用户明确要求提交当前变更并去掉网页端。

## 决策

`desktop/` 为唯一主应用。退休根 `web/`、`src/`、旧网页测试、Node/Nest 服务、网页部署与根 Vite 入口；
不保留第二套认证、组卷、存储或 PDF 运行实现。旧版本从 Git 历史追溯，不通过并行目录继续开发。

桌面所需的 token、富文本解析与来源显示迁入 `desktop/src/`，迁移时内容字节不变。
界面、题库手动组卷、公式、图片、表格及学生／教师版本边界不因路径迁移改变。
根 package.json 仅转发桌面命令；React、Nest、旧 AI SDK 和网页 PDF 等依赖从根锁文件移除。

保留显式离线共享题库／标注导出和旧整卷来源准备工具，使用 Node 内置模块；哈希工具及隔离回归独立保存。
少量教材资料准备脚本保留，不成为桌面用户安装依赖。`data/`、来源资料和历史验证记录保留。

## 数据与验证

不删除或重建任何用户数据库，不合并旧个人记录，不修改已有成卷、PDF 或本地题库。
删除前将未提交的旧源码备份到仓库外；备份不包含实际 `.env`、数据库或桌面运行目录，不进入提交。
EXE、日志、调试截图、交付临时目录和密钥继续排除在 Git 之外。

验证桌面构建、完整前端回归、隔离 Rust 测试和维护工具测试；浏览器使用隔离 Rust 数据验证主要交互，
不能以复制文件或模拟服务本身声称真实教师使用或真实 OCR／评分质量。
