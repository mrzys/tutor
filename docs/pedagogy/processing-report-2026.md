# 教学目标分析修复与题库扩充报告

日期：2026-10-10。依据：[ADR-0001](../adr/0001-assembly-workflow.md)、[ADR-0002](../adr/0002-question-bank-blueprint.md)、[ADR-0003 草案](../adr/0003-teaching-requirements.md)。

本轮修复了错误题面、答案、版本绑定和过度支持判断，并从既有50个集合源单元新增27个真实题包。**当前普通组卷供给为45题；独立复核通过的教学目标分析仍为0条。** 两项数字不能互相替代。

当前45题按题型为30道单选、13道填空、2道解答。新增供给扩大了集合相等、对象类型、子集计数、新定义、区间交并补等任务；029、030、031共享同一个新任务，因此**新增24个任务，目录从10项增至34项**。

新增27题只完成题面、答案、完整允许解法及任务供给接入，没有自动生成或批准知识点、认知要求、能力与核心素养的目标支持证据。解答题仍只有041、050两道，书面推导、综合论证及重复换题的供给仍有限。

## 4. 目标证据修复

下表描述当前文件中**待复核的判断内容**，不把模型给出的 `supported` 字符串视为已批准支持。

| 案例 | 修复后的判定边界 |
| --- | --- |
| 018 | 用户已确认补充“两个不同元素”。a=4使基数降为1，不满足明确条件；并非 $\{4,4\}$ 是非法集合。填空不要求书面证明 |
| 050.p1 | 仅具体参数下求区间补交集，对包含含参求解、包含转化的整个区间目标只能部分支持 |
| 050.p2 | 提供空交集转化及端点推导活动；N长度恒为2，不能当作N为空的退化分支训练 |
| 普通书面推导 | 使用新目标 `obj-written-derivation-01`，要求组织步骤与关键理由；不自动包含反证法 |
| 自主反证 | `obj-proof-formal-argumentation-01` 明确要求建立反证假设、构造矛盾并回扣结论。041、050的普通求解不支持此目标；全国Ⅰ卷19.p2虽可反证，也存在直接证明路径 |
| 049 | 替代解法保留 $ax^2-bx-2$：代入端点得 $a+b-2=0$、$4a-2b-2=0$，解a=b=1后回代检验符号。此法不用韦达定理，但需要 `quadratic_basics`；分析记录不自动修改已登记选题路径 |

认知要求描述题目所需活动，与经验难度、学生当前掌握程度分开。能力和核心素养由活动证据支持，不按题号或关键词推导；七维认知负担仍是可选工程特征。

## 5. 引擎实测与局限

2026-10-10 使用当前真实数据调用 `previewBlueprint`、`recheckBlueprint`、`createDraft`，覆盖全部34项任务：

- 测试蓝图为20单选＋12填空＋2解答，共34题位、340分；该尺度只用于覆盖任务，不是教师认可的实际试卷配比。
- 全任务实验显式启用全部工具前提：`vieta`、`quadratic_basics`、`absolute_root`、`basic_geometry`。014、017所需的初中几何边长性质未列入自动基础依赖，必须在本次需求中明确允许；`basic_geometry` 默认不勾选，不能随题包就绪静默注入。
- 34个题位均有符合已登记任务、章节与前提约束的候选，内存草稿选中34/34，缺题0、有效分值340，来源读取失败0。
- 检查没有保存草稿或写入用户组卷历史；不能代替教师验收，也不证明四维教学目标的实际覆盖。
- 题包阅读器、内容哈希、来源与公式检查，以及038、040等数学检查见扩充记录；结构检查通过不自动提升目标复核状态。

可重复执行的全场景结果见[扩充验收记录](../validation/question-bank-expansion.md)及[运行结果](../validation/question-bank-expansion-results.json)：同一集合相等任务连续4题位仅选中3道不同题，第4位留空；把已学边界收窄到1.1并撤销全部显式工具时，34题位只选中12题，其余22位留空，有效117分。原默认蓝图仍为10题／100分。34项任务中28项只有一个候选，数量增加仍不能代表充分的换题多样性。

根代理最终验收通过：102项全量测试（含显式几何边界检查）、45题题库检查、分析校验、蓝图检查、前端构建及桌面/手机操作；主服务只读检查显示45就绪／5待处理和34项任务。此处引用工程验收记录，不把通过的工程检查改写为教学目标复核完成。

下一步按12项目标的具体定义和版本独立复核已有28条分析，再对新增27题分批补分析；高考题需先建设具备完整题面资产、版本与范围证据的题包。当前先用扩大后的任务供给测试蓝图与换题行为，同时保留目标证据不足和解答题供给不足的真实差异。
