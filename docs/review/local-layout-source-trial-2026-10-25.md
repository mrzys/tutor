## 结果

本轮保守阅读视图没有证明优于旧索引：655 个原始块全部保留，本地合并减少 0 个块；9 组同时收到响应的 Plan 输入 token 从 56,239 增至 65,767（+16.9%）。这不是已实现“强力前置整理、减少 50% 碎块”的版本，不能据此否定整个方向，也不能宣称已有压缩或稳定提速收益。

- 新方案完整转录 5 卷、97 题；失败卷内另有 22 题成功批次缓存，共 119 题已接受来源转录。
- 巴中另 3 题原始响应正文正确，但整批被页码契约拒绝，未计入上述 119。
- 74 道预冻结定点细审：45 道符合整理要求；安徽 17 多带章节说明 1 道；28 道未产出正文，保留 unknown。已产出的 46 道细审题未发现必要数学题面丢失。
- 119 题模型自评为 110 ready、9 needs_review；均不是独立数学正确性或可入库证明。
- 本轮未运行独立教学稿生成、Qwen 或 OCR，不入库。来源转录仍沿用普通导入同响应的元数据字段。

## 样本与比较口径

用户明确选择从已有 OCR 的 19 份真实数学试卷中随机抽 10 份。种子先提交后抽样，失败不替换。顺序：北京延庆、河南、惠州、巴中、福建、重庆、贵州、安徽、南京、江西宜春；共 53 个物理页、192 道原题。

种子：`141368762134721651275059514944981434743`。算法为 CPython `random.Random(seed).sample(poolSortedBySourceSha256, 10)`。

两版使用同一已校验 OCR 和各自隔离目录；旧版仅 Plan，新版 Plan 加完整分批转录。因此只比较同任务的 Plan 输入与请求耗时，不计算端到端新旧加速比。9 组配对 Plan 耗时合计 181.5→170.2 秒，但每卷只跑一次，不能排除网络和服务随机波动；贵州旧 Plan 没收到响应，不虚构其 token 数。

独立审稿先目视全部原 PDF 并冻结核对清单，再查看候选。预冻结详细清单为 27＋25＋22＝74 题；福建 11、贵州 9 等事后补查另列，不扩张原分母。覆盖通过、模型自评和技术完成均不冒称数学正确率。

## 实际失败与缺陷

| 类别 | 样本 | 证据与处置 |
| --- | --- | --- |
| 程序题号误拦 | 河南、宜春 | 两版原始 Plan 都正确列出 19 题，检测器漏掉 OCR 中第 18、19 题标题，仅数到 17。不是模型虚构题目。 |
| 共享说明页契约 | 巴中 | q4–6 正文完整；q6 包含第 1 页共享说明块，却只填写本题第 2 页，触发 `source_batch_scope`。前 3 题缓存，原始拒绝响应保留。 |
| 连接失败 | 惠州、南京 | 约 21 秒在响应头/建连阶段超时，OS 10060、无 HTTP 响应。120 秒是上限，不是模型思考实耗。前 16、3 题分别缓存。 |
| 多余章节说明 | 安徽 17 | 跨页和三问完整，但题干多带章节题量/分值说明；需清理，不是数学错误。 |
| 原始材料不完整 | 北京 21 | 原 PDF 参考末尾缺证明后续；模型未补造，保留缺页提示。 |
| 原卷记法疑点 | 贵州 9 | 原 B 项本就未写 `x=`，转录忠实；不能自动补字改变选项。 |

贵州 6、7 从同一个 OCR 块实际拆成两题；重庆 10、17、18、19 四处跨页正文和图表归属通过。安徽 18 原 OCR 的导数阶数和分母错误在实际转录中被正确纠正，LaTeX 命令实际单斜杠正常。未验证正式应用 UI/PDF 显示。

## 实现与验证

- `imports/layout_reading.rs`：无损紧凑行视图、候选题号锚点、邻图及阅读提示；保留原块身份、原文、素材哈希。不依本地提示决定题目或图表归属，不猜测未知顺序。
- `imports/source_trial.rs`：debug 专用隔离入口、原件/OCR 校验、旧候选拒绝、空记录初始化、Plan-only 与 source-only 执行。显式试验 marker，执行器白名单不含发布动作；不宣称 marker 是所有 API 的通用发布安全门。
- `imports.rs`、`imports/source_batches.rs`、`model.rs`：复用真实 Plan 和逐批来源校验；正式默认行为不切换。试验跳过独立教学稿阶段。
- 阅读视图 7 项通过；来源相关回归 38 项通过、1 项忽略；debug driver 构建通过。
- 实际请求审计：20 次 `question_import_plan`、63 次 `question_import`；未观察到 Qwen、独立教学或新 OCR 产物。不把请求审计冒充网络抓包。
- 前后校验 240 个原始证据、520 个复制输入、2 个真实配置、11 张真实题库表均未变；题库仍 392 题，未读取真实个人数据库。

应先修复已证实的题号误拦和共享说明页契约，再只恢复失败/未发起部分。后续阅读整理版本必须先证明实际压缩收益并继续保持原始身份及完整性；当前不足以支持替换正式流程。
