# 普通试卷导入与课堂教学稿同步验证

日期：2026-10-24。按用户要求，将已采用的“DeepSeek生成、规则命中后Qwen开启思考复核一次、未解决保留待复核”接入普通导入流程，并从指定的`C:\baidunetdiskdownload\高--模拟题`选取10张真实数学试卷试跑。这是原卷回归与工程验证，不是真实教师使用或教学效果研究。

## 已实现的边界

- 原始PDF经过`import_prepare`、PaddleOCR及DeepSeek来源整理。原卷缺少答案解析时保持空白，新生成稿单独保存。
- 来源身份、内容与素材校验通过后，DeepSeek分批生成课堂解析、难度依据、考点及学生要求。短题每批最多3题，多小问或较长解答题单题发送。
- 共享规则检查生成稿的术语、结构、完整性及可检测显示问题；不替换文字、不判断数学正确、不强制特定解法。
- 命中才使用独立保存的Qwen3.8 Flash配置，开启思考，每题最多复核一次。实际请求前持久化次数；失败、中断或残留保留标记。读取历史不再次外呼。
- 两个角色分别访问其provider模型列表；不共用密钥、不修改用户的活动模型配置。缺少配置明确提示，尚未发起的工作可显式继续。
- 来源编辑使原教学稿失效；发布及幂等重试均检查实际请求、响应、源版本与哈希。前端不能伪造通过状态。
- 审核页、题库详情和教师卷区分来源解析与AI教学稿。来源已人工核对但教学稿未通过时，允许沿用原有来源入库权，教学稿仍保留待复核，不冒称通过。

详见[导入工作流](../design/import-teaching-workflow.md)。

## 数学与课堂质量的已知边界

固定抽样在候选生成前确定为每卷原题2、8、16，共30题；先独立推导，再查看模型候选。候选审计绑定实际执行身份和候选哈希。技术失败、没有完整稿或未核对保留未知，不算数学错误，也不算成功。

扩展核对天津卷12道未触发复核的候选，答案12道正确、关键证明10道完整、课堂可直接使用9道。问题包括将一个周期当成最小正周期、最远点方向描述错误，以及概率推导的条件说明不当。这组扩展样本不能外推全体题目正确率。

湖南卷第8题的答案正确，但直接断言四球心均匀形成正方形最优，缺少任意构型都不能放入更大球的证明。简短补法是圆周四个间隔角和为360度，至少一个不超过90度，从该对球心距离与不重叠条件推出半径限制，再验证正方形能取到。它没有术语命中，说明词表不能发现一般证明缺口。

大连卷第13题要求切线“与x轴平行”。DeepSeek和Qwen均只令导数为0，多列了切线与x轴重合的点`(1,0)`，并误报题干缺陷；按高中平行与重合的区别，只应取`(-1,4/e)`。该题被保留待复核，没有入库，但这不能统计为Qwen成功纠错。

本轮中途有工程修复，各卷并非使用同一二进制版本，未将所有早期失败卷统一重测；本次完成比例不是最终版本稳定成功率。

当前流程已经接入，术语词表与一次跨模型复核仍不构成数学正确性的保证。本次试跑不能支持95%的全卷处理或课堂可用率，也不能依据规则无命中自动放行新题。
