# 教学稿触发覆盖与Qwen超时排查

日期：2026-10-24。范围为本次8张已整理试卷的155题、实际请求审计与既有Qwen试验；本次没有调用真实模型、OCR，没有修改题库、个人数据库、模型设置或旧处理结果。新增命中不等于数学错误。

## 规则补充

共享词典升级为`teaching-term-review-v3`，Rust普通导入与JS离线维护同步。固定匹配器只定位新生成的答案、教学解析、难度依据、考点和学生要求，原题、原卷参考与教材知识点不参与术语扫描。继续保留每个命中的规则ID、字段、UTF-16原文位置、具体文字及检查建议。

| 新覆盖 | 例子 | 复核方向 |
| --- | --- | --- |
| 积分工具 | 积分得、积分常数、不定积分、`\int`、∫ | 结合已学范围，必要时写出具体函数并求导验证，或构造导数为0的函数 |
| 二阶／高阶导数 | `f''`、`f″`、`f^{(2)}`、高阶微分分式 | 检查能否完整改为一阶导函数的增减性论证，不只改名 |
| 无穷求和 | 无穷等比级数、几何级数、`\sum_{i=3}^{\infty}` | 检查可否用有限项求和或具体不等式闭合证明，不直接改求和上限 |
| 明确英文方法名 | telescoping、geometric series | 写出对应中文方法及本题实际变形，不检测所有英文 |
| 不写lim的端点写法 | `h(0+)`、`f(a^+)`、`h(+\infty)` | 检查增长断言是否有高中范围的实际证明 |
| 既有要求的漏项 | 线性组合 | 写出本题实际系数相加或向量等式，是否保留交由模型结合语境判断 |

正常一阶导、有限项求和、`(0,+\infty)`等普通区间、`f(x+1)`等函数运算，以及合法LaTeX命令子串均有负例。不同平台扫描共用正负例并验证命中原文位置，避免JS增加规则而Rust遗漏的情况。

不能把上述概念一概称作大学专属。[教育部关于高中课程分层的说明](https://www.moe.gov.cn/jyb_xxgk/xxgk_jyta/jyta_jijiaosi/201912/t20191206_411058.html)明确区分必修、选择性必修与选修，数学选修内容涉及微积分。另据[人教社刊载的教育部教材局访谈](https://www.pep.com.cn/rjdt/mtbd/202603/t20260330_2005956.shtml)，2025年日常修订版已印发，不能把旧版本目录描述成唯一现行要求。本规则针对项目已确认的普通高中课堂表达，只触发模型检查教材及已学边界，不承担完整课标合规判定；2020课标PDF直接获取超时，未声称逐页核读。

## 超时证据

当前155题中实际发起17次Qwen复核：6次收到完整响应，11次`model_request_timeout`。11次均在120.03～120.13秒结束，根据实际错误路径可定位为`send().await`未返回HTTP响应头；没有正文读取阶段的`model_response_timeout`。

这些请求都是单题、千问AI平台`qwen3.8-flash`、`enable_thinking=true`、非流式、`max_tokens=16384`。同卷复核顺序执行；模型列表为单独25秒总预算／10秒连接预算，不能与实际复核请求混算。6次成功耗时约36.19、40.08、56.78、110.25、115.14、115.34秒。

历史同provider／模型开启思考的单题试验，有147.107、156.996、279.229、281.979秒完成的实际记录。历史题目、提示词、输出预算和并发不同，部分旧脚本使用的是socket读超时而非整个请求总时限，因此只证明有效单题可能需要超过120秒，不能预测本轮11次在300秒内必能成功。

能确认的是客户端120秒**整次请求总时限**触发，不是每个网络阶段各120秒。未收到响应头不等于请求未送达，也不等于服务端没有计算。失败没有usage和完整网络时间线，无法进一步把耗时分配给服务端排队、模型思考、DNS／TLS／代理或其他网络等待，不应直接声称是服务商故障或模型不会做题。

## 修复

1. 对发送上下文去重，不删除完整原题、完整稿件或疑点。13/17份旧请求有完全相同的candidate与rawCandidate；相同副本用显式同稿标记指代，格式不合法或不同的原响应仍逐字保留。每个命中改为短摘录，重复guidance用索引引用。存档与旧审计不变。
2. 只读重构17份旧请求，保持旧系统提示词不变时，总请求字节从193856降至147501，减少23.9%；重庆19从25302降至11349字节。此为上下文投影比较，实际新提示词另有说明文字，不冒称已实测提速。6.2KB请求也有超时而15.8KB请求成功，体积不是唯一原因。
3. 仅千问AI平台精确qwen3.8-flash、单题originalMaterial.questionId非空且无questions批量键的教学复核，改为300秒整次HTTP总预算。依据是既有成功单题的真实耗时，不改变思考开关、输出预算或其他任务的时限，不扩大整卷请求。取消与每题一次复核保留，不自动重试或清零历史额度。
4. 为带审计路径的来源／教学请求新增独立`.transport.json`。HTTP前独占创建，记录安全字节数、输出预算、思考／流式开关、总时限、响应头与正文各阶段耗时、HTTP状态和结果码；成功、超时、取消均更新。无认证头、地址或业务正文。诊断创建或写入失败明确报错，不能静默宣称采集完整。

300秒仍可能失败；当前11次旧失败没有自动恢复，也没有重复外呼已花费复核额度的题。诊断新增后，后续显式执行才会产生新的传输记录。
