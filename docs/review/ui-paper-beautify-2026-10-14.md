## 二、试卷编辑页（`/drafts/:id`）

1. **题卡化**：每题一张白卡——1px 发丝线 + 12px 圆角 + 20/24/18px 内边距，不用阴影。选中态改为发丝线加深（`#171717`）而非背景色块。
2. **题号做胶囊芯片**：24px 圆形、`#fafafa` 底 + 发丝线；选中时反相为黑底白字（规范允许的"反相为深色面"）。
3. **题干层级**：16px / 行高 1.85 / `#171717`，比元信息重一档；选项、小问统一到同一阅读字号（原来题干 16px、选项 15px、元信息 12px 三档并存）。
4. **选项**：A/B/C/D 字母做成 22px 小胶囊（`#fafafa` + 发丝线），与文本基线对齐；行间距 8px → 12px。
5. **题卡底部操作区**：卡内改用上边框收口（原来是通栏下边框，卡内会造成双线），操作按钮统一胶囊 + 13px + `#525252`。
6. **分组标题**：题型分组 17px → 20px，行距 `.01em`；副标题 12px → 13px。
7. **来源 / 分值**：`--font-caption` 13px，数字 `tabular-nums`，避免两位题号与分值跳动。

## 三、成卷纸面（`/papers/:id`，`.frozen-student`）

1. **卷面容器**：限宽 880px 居中、12px 圆角、发丝线边框、内边距 `40px clamp(20px,6vw,72px) 48px`。
2. **卷头**：标题 24px 居中，下方加一道 1px 墨线（`--ink`）——试卷最容易被认出的结构。
3. **正文**：整纸 16px / 1.85（原 15px）；题型小标题 16px 600；题间距 28px。
4. **教师资料**：虚线发丝线上分隔，小标题 13px。
5. 文档状态行、卷头元信息：12px → 13px；工具栏按钮改胶囊。
