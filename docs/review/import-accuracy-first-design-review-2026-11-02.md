- 日期：2026-11-02。

- 核对对象：[ADR-0010](../adr/0010-import-accuracy-first.md)、[详细设计](../design/import-accuracy-first-redesign.md)、实际 Rust 合同与已采纳 ADR。
- 评审时状态：设计修订完成，仍为草案；当时没有将外部模型“建议采纳”当作用户采纳，也未修改应用、密钥配置、AGENTS.md 生效规则或运行数据库。后续用户采纳记录见文末，以下表格保留评审当时语义。

## 1. 结论

补齐两份评审指出的决策清单、成本边界、人工发布政策、目录快照、新旧投影及过程保留策略。优先试点“模型只返回教学字段、Rust 受限组合”的路径，避免要求模型复读已核验的数学稿；真实执行和组合规则仍完整重放，最终内容/教学信息/OCR 结构不变。

三点范围校正：

1. ADR-0002 的“未知或缺项不取消用户确认权”在草稿/成卷交付语境，不能直接推导有问题的题库入库权。新 `source_only` 确有需要明示的收紧，但依据是当前实际人工发布路径，非取消教师组卷最终决定权。
2. 当前 `source_only` 不等于“无教学元数据”。它可发布主考/路径/难度，只不采用待核独立教学稿；新门槛须按实际交付字段检查。
3. 两份 review 给出的分钟/小时预期均未有当前新流程实测支持。20 题调用量取决于每阶段批数；文档列出条件化算例与预算，不冒称 ETA。

## 5. 修订验证与未决事项

本轮只验证文档引用、字段边界、调用/令牌算术、链接和设计一致性。没有运行新管线、没有测试新模型真实质量、没有证明 D3 已满足原审计兼容。

待采纳决策为 ADR 的 D1（核验覆盖及预算）、D2（新人工发布门槛）、D3（受限组合）。真实试点前还需冻结实际原卷/目标清单、具体配置、金额预算或费用未知的执行选择、独立审阅人员/准则。首轮预算上限不等于已授权付费执行。
