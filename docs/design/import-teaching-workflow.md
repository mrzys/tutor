# 试卷导入与课堂教学稿

2026-10-24用户明确要求普通导入与已采用的教学稿维护流程一致。本轮在Rust导入执行路径中实现，真实原卷试跑和工程验证分别记录，不能以规则通过冒充数学正确或真实教学效果。

## 执行过程

### 2026-11-01：单题视图、局部响应与持久进度通知

桌面审核页先通过 `import_summary_get` 读取导航摘要，再用 `import_question_get` 按需读取当前题。摘要保留原题号、页码、实际资格与处理状态，去除题目正文、图片字节、OCR全文和模型历史；`_detailLoaded: false` 明确表示未取得完整题目，不能用于编辑或保存。单题详情带完整目标题及其实际核对、题库版本和来源凭据，其余题仍为摘要。显式重新打开重新读取派生绑定，同一快照内普通切题可复用已读正文。

单题原题保存使用 `import_question_review_save`，与原保存共用规范化、素材、不可变字段、来源修改失效、总长度、重复、修订、整条记录CAS及幂等校验；非目标题保持原样。教学修订仍走独立受限接口，不自动重绑定修改题干后的旧解析。多题未保存编辑继续一次原子保存，先按原快照补齐未读题，版本变化时保留输入并失败。旧整卷接口默认响应保持兼容；`responseScope: "summary" | "question"` 仅选择紧凑响应，不能减免审核。中断发布保存并重放原请求（包含原响应范围），旧记录只有原请求哈希吻合才重建，不猜测丢失参数。

每次导入事务提交成功后，按本机数据目录发送轻量 `import-progress` 失效通知；后台worker、Tauri和隔离stdio驱动共用跨线程出口。事件仅含导入／任务身份、阶段、状态、修订及进程内序号，不含题文、密钥或学生信息，不作为完成或审核凭据。失败写入与幂等重放不产生新提交通知，监听失败不能撤销已持久化成果。

界面先订阅再读取持久状态；正常运行取消定时轮询，合并突发通知后按需补齐。窗口恢复、页面重新可见、网络恢复及显式重新读取都会补齐本机状态；断线和丢事件不能据事件缓存宣称任务完成。存在原题或解析未保存编辑、正在提交或待发布确认时，保留输入并延迟详情更新，解除保护后消费待补齐状态。编辑缓冲保留原快照和写入基线，撤销后显式读取最新状态；晚到的摘要或单题响应不得覆盖随后切换、重新打开或编辑的内容。

原卷全文对照的识别文本图片按页显式请求只读审核素材context，依次核对原件、manifest、实际页码、唯一裁图身份、归属与字节哈希；缺失或歧义明确失败，不依赖尚未读取的其他题正文，也不把原页或审核context加入学生素材。查看与补齐不重新识别、不调用模型、不修改来源或冻结成果。

### 2026-11-01：进度条件读取与投影复用

导入详情的教学核对投影统一在响应出口计算；题库配置仅在本次动作投影内惰性读取一次，实际发布仍重新读取和核验。维护入口直接调用的核对响应保持兼容，不跨请求缓存审核资格或题库版本。

完整详情附带 `detailVersion`；`import_job_get` 可提交 `knownDetailVersion`，与持久 JSON 字节的 SHA-256 一致时只返回导入身份、快照标识和 `notModified: true`，不展开 JSON 或计算详情投影。此标识仅用于轮询协商，不是审核修订、素材校验或发布授权；读取仍查询本机数据库并计算摘要。无标识或不匹配时保持完整响应，显式 `import_get` 始终读取完整详情。中断恢复先于比较；同审核修订号、同时间戳下的成功断点、阶段、题目或错误变化也返回新详情。

前端收到未变化响应不替换题目；新快照须在当前记录及未保存编辑保护仍有效时采用，过期轮询不能覆盖随后打开或保存的记录。所有写入继续使用原修订、内容哈希、素材、幂等和发布校验，不因快照标识相同而跳过。

### 2026-10-28：短编号协议与相关小问方法改写

### 2026-10-27：极限论证的课堂改写与中文问题提示

新生成使用`classroom-analysis-v8-concrete-limit-proof`，词表为`teaching-term-review-v6-classroom-limits`。默认课堂稿须以具体不等式、明确取值或导数单调性说明结论，不以lim、单侧极限或ε—δ定义直接完成论证；题面给定信息和定义原样保留，无法满足当前范围时具体保留疑点。

新句段合同另带`classroomPolicyVersion:1`；极限命中项声明`requiredAction:rewrite_without_limits`。这是用户明确选择的课堂表达要求，不是规则判断数学错误。该项不能仅凭模型称“极限用法正确”而以`false_positive`撤销；须改写或保留未解决。已修改字段仍重扫；只换术语不能证明推导合格。程序不验证全部数学语义，独立核对仍须检查必要理由、范围和具体取值。没有足够句段权限时保留初稿待核，不扩权、不循环或自动重生。

该策略只用于新请求。旧合同没有此版本时保持原义，即使外围出现新偏好也不静默迁移；旧稿、旧额度、旧待核和已合格记录不变。新增ε—δ搭配检测仅定位同句内带量词的论证，独立希腊字母变量不因此命中。

普通界面通过共享展示函数解释问题，例如`literal_newline_escape`显示为“解析中存在未正确处理的换行符，需修复排版”；未知内部码采用中文核对提示。导入正文、右侧待办与题库详情使用同一映射，原始码及精确绑定仍保存在底层，不据显示文案改变入库资格。

### 2026-10-27：再次求导与二阶导数判别法分开处理

新生成使用 `classroom-analysis-v7-derivative-scope`，词表升级 `teaching-term-review-v5`。再次求导、二阶导数名称、`f''`、Unicode 双撇、`f^{(2)}` 和完整二阶微分分式不再仅因记号触发复核或要求改写，不强制另设函数或换名。需完整交代导函数的增减、正负与原函数结论之间的关系。

明确引用二阶导数极值判别法等未说明的理论仍由 `second-derivative-test` 定位；凹凸性、拐点、中值定理及三阶以上导数的上下文规则保留。规则不判断证明是否正确，不为放宽记号而隐藏数学／证明／材料疑点；同次模型质量自检及明确核验意见继续触发一次复核。

主生成、同次自检、句段补丁、旧字段补丁及完整结构恢复指令同步此边界。只影响新请求；旧稿、旧提示词／命中、复核额度和待核状态不自动修改或放行。已合格稿不重跑。

### 2026-10-26：复核意见处理版本2

新请求保留句段写入合同`segmentPatchVersion:1`，另以`resolutionVersion:2`区分意见处理语义。质量意见、材料意见及术语命中分别逐项返回`qualityResolutions`、`issueResolutions`、`termResolutions`；状态只能是`repaired`（已实际修复）、`false_positive`（核实误报）、`confirmed_defect`（确认缺陷仍在）、`unresolved`（未解决）。确认缺陷不是“已处理所以可放行”，后两项继续阻断，任意未解决项使本次合并失败并保留原稿、响应与一次额度。旧`resolved`不能用于新合同；保存的旧合同及旧审计仍按原版本精确重放，不重新解释为新批准。

`repaired`必须对应获准文字的实际变化：质量意见检查具体`fieldPath`，术语检查其所在字段；材料意见不能仅凭删意见或改难度依据声称修复原题。字段变化只能证明有实际改动，不证明数学已改对；句段权限、原题/候选版本、公式范围与实际响应继续校验，补丁失败不扩大权限或自动重试。完整有效候选继续使用句段补丁，结构损坏稿的完整恢复入口保留，不能借格式恢复改写无关正确内容。

词表继续只提供检查位置。v4曾使用完整微分分式语法定位二阶及以上导数，避免把普通`d²/(e^d-1)`误判；v5进一步将记号触发限制为三阶及以上，允许再次求导。“上界、下界、线性表示”等上下文命中不一律判错；模型可对确切命中声明`false_positive`并给当前材料依据。该结论绑定原题与候选哈希、规则、字段、词句及位置，仅过滤该处未变化字段的相同命中；字段、版本、位置或规则变化后不沿用，新出现的命中仍检查，不建立全词白名单。误报说明仍是模型判断，不等于独立验算。

   受限范围为完整的教学文字字段，而非句级或公式片段锁定。可修改答案、教学解析、难度依据、考点与现有学生要求的单条文字；不能修改题面、原卷参考、素材、UID、题目身份、难度档位或增删数组元素。模型仍负责理解原题与方法适用性，程序不按关键词决定数学错误或强制选解法。只控制写入范围不能证明替换内容正确，也不保证模型思考更快。发送前继续去重相同稿件与重复建议，题面、完整教学稿、疑点和命中数不截断，原存档不变。
6. 合并后重新检查结构、字段完整性、术语和显示；残留、失败、未解决疑点及缺必要材料继续待复核，不自动再调用Qwen。原始`issues`不因“已处理”而删除。逐条实际核对原题、答案、解析和公式后，教师可将具体参考笔误或不影响该稿使用的观察显式确认为非阻断提醒，并填写依据；未确认意见仍阻断。分类来自这一具体确认，不由词表或模型自评自动决定。原题保真、素材、身份、版本和精确重复等硬性问题不能借此放行。候选内容或来源版本改变后旧确认失效。规则无命中、显示正常、模型高置信或JSON合法都不等于独立数学核验，合格候选仍沿用现有入库确认边界。

## 模型与界面

### 2026-10-25：来源失败的精确恢复

用户要求修复十卷试跑中四卷的来源阻断，复用已保存OCR和成功结果，不重复生成已有候选。以下是来源完整性与恢复实现，不改变教学稿的DeepSeek生成／Qwen命中后复核一次及入库确认边界。

- 本地模型、角色与OCR配置仍在导入前检查。历史试跑曾在OCR保存后核对在线列表；2026-10-30起取消此执行前置步骤，直接使用已保存模型，实际推理接口失败保留OCR与成功断点，不换服务商、密钥或型号。
- PDF检查增加非常窄的兼容读取：仅对最终`startxref`指向的空经典交叉引用节，在内存检查副本中补零条目分节，保留最新trailer、已有对象与全部对象偏移。继续执行加密、页数与OCR返回页数检查；上传给OCR的原PDF字节不改写，`pdfInspection`另存检查方式和哈希。不将它作为通用损坏PDF修复或忽略加密的入口。
- 短卷若已有完整且实际HTTP 200、`finish_reason=stop`的来源响应，仅因题号覆盖检查失败，可在用户显式继续时先本地重放。重放校验原件、OCR、旧attempt、实际请求／响应、原context与素材身份；重新执行当前完整拆题校验和同次来源意见处理。旧失败attempt不改成成功请求，新`sourceResponseReplays`只追加独立操作及结果，不伪造新的HTTP或清除原失败。绑定不符、截断或重放仍失败时停止，不自动再请求模型。
- 来源索引若已因题号身份校验失败，显式新操作可附已校验OCR保存的全部原页PNG重新核定索引；实际图片及原失败attempt哈希进入审计。首次索引和已有成功索引不扩大请求，不重复处理成功批次。缺少唯一原页或模型不支持实际看图时阻断；不按顺序补号，不改写OCR，原页仍不能确认的题号继续待核。
- 长卷在所有成功来源批次之外另存`sourceMaterialSupplement`，只补核未覆盖的保留素材，原批次、题文、答案解析及知识身份不重生成。补核实际投递孤立图片、同页原图、已有图与已保存题目的对应信息，由模型明确题目、角色、真实原文块和呈现位置；程序验证精确身份、范围、实际投递像素与请求／响应审计。不能因图片缺少布局关联就删图、猜角色或放宽整卷素材覆盖。
- 模型建议另一图可代表该素材时，只有同题、同角色、代表图确已呈现且程序核对精确像素包含，才能避免重复显示；近似相似或有损压缩差异不作为等同证明。缺少严格证据时保留两张原图，并向受影响题的`sourceIssues`、`reviewIssues`写入具体阻断意见；不把可定位到单题的问题泛化为全卷失败。补核无法可靠归属时保留失败和实际响应，不能通过置信声明忽略缺图。
- 素材补核若已取得完整HTTP 200且正常结束的回复，但本地合并失败，显式继续先重放该实际回复，不重新请求模型。历史缓存缺少可选的`sourceIssues`时仅初始化空数组，非法类型仍拒绝；原失败attempt和审计原样保留，另记`local_validation_replay`及原attempt哈希。重放仍失败时立即保留失败，不落入新请求分支。
- 发布时从原成功批次与实际素材补核审计重放派生素材结果，继续检查完整覆盖。合并只允许追加经核对的素材引用、角色与具体意见；不因来源恢复而重置已用教学复核额度，不覆盖既有教学候选。历史阅读及重放核验不访问OCR或模型。

## 验证口径

### 2026-10-27：显式补充考查信息可参考有效课堂稿

来源转录不生成正式知识点或解法依赖；课堂稿已有难度、考点与解析，也不等于已完成 `primaryKnowledgeUids`／`solutionPaths` 标注。用户点击“补充考查信息”时，元数据请求可以附上当前 `ready_candidate` 的完整课堂稿作为 `teachingReference`，但须先通过候选结构、来源内容哈希和现有待核状态检查。失败、待核、缺稿及来源失效稿均不发送；读取历史不触发补充任务。

该参考始终标明 `llm_generated`、非原卷参考、非独立数学核验，候选与来源哈希随请求保存。模型只可在核对其实际推导足以覆盖整题与所有小问后标注真实目录中的知识 UID 和解法依赖，路径依据注明“AI教学参考，非原卷解析”；仍有关键缺证或推导错误时路径留空。请求不能重做课堂稿，响应仍只有元数据白名单，原卷答案解析、教学稿、来源素材与已有审核不变。“已有有效课堂稿但缺解法依赖”可被显式补充命中，不因此重跑已完成的生成或复核；原题无解析也不再被误解为永远无法依据独立课堂稿整理依赖。

工程回归覆盖角色与凭据隔离、词表命中、来源字段隔离、复核额度、取消／恢复、原题修改失效、拒绝伪造状态及正常确认门槛。10张真实试卷使用隔离数据目录，固定每卷原题2、8、16盲算后对照候选；技术失败和无法判断分别计数，源题错误与模型推导错误分开统计。样本外不外推放行，不自动写入用户当前题库。
