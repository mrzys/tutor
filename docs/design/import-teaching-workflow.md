# 试卷导入与课堂教学稿

2026-10-24用户明确要求普通导入与已采用的教学稿维护流程一致。本轮在Rust导入执行路径中实现，真实原卷试跑和工程验证分别记录，不能以规则通过冒充数学正确或真实教学效果。

## 执行过程

1. 用户明确上传原始PDF／DOCX／文本。文档沿用独立PaddleOCR配置，保留原件、逐页材料及实际图表；历史阅读不调用OCR或模型。
2. 2026-10-26用户采纳正式PDF／DOCX导入统一采用“整卷索引 → 分批转录”：DeepSeek Flash/low读取紧凑OCR块与实际原页，只确定整题边界、原题号、题型及对应来源块，包含跨页小问和实际原卷参考。之后按短题最多3道、解答题单道分批，只发送本批原块、原页和相关图表；3个常驻worker有空即取下一批，不等待整组完成。索引和来源转录共用每次显式操作120秒硬截止，包含该阶段的服务商列表检查、等待与传输，不含OCR、课堂教学生成及人工核对；不是整卷全部处理保证两分钟完成。成功批逐个保存，失败或中断只在用户显式继续后处理未完成部分，HTTP完整stop已保存而本地保存中断时优先核验重放，不重复外呼。TXT／Markdown与旧成功缓存保留原兼容路径。原卷没有的答案解析留空，不把新解答写成原卷参考；来源阶段不生成课堂稿、解法知识关联或难度，知识关联不足可由现有“补充考查信息”显式补齐，不添加自动补标请求。

   2026-10-24失败恢复进一步精简来源任务目录：保留全部真实任务的ID、名称、题型及小节身份，不发送旧试卷的来源正文、审核理由或候选说明；教材及知识点身份不删减。来源整理不再为了填写解法字段求解全卷，原卷无可靠解法时相关字段留未知，独立教学稿仍在后续生成。DeepSeek思考模式的这两个导入任务使用64K总输出预算，包含思考及正文；依据[官方API合同](https://api-docs.deepseek.com/api/create-chat-completion/)，不改变用户保存的思考偏好或其他任务／provider参数。
3. 题目身份及素材校验通过并保存后，DeepSeek有界生成独立课堂教学稿：选择／填空等短题每批最多3题，多小问解答题或长正文单题发送，避免几道长解析共同耗尽一次输出预算。该分批只控制实际输入输出体积，不用题型代替数学难度判断。使用与维护入口相同的主提示词，不默认附加全部方法参考。只交付本批实际题面、参考和相关图表，不重复发送全卷。难度依据说明本题难点及所属档位，课堂解析使用普通高中学生可理解的术语，考点与学生要求另存。
4. 校验新稿的结构、真实题目ID、字段完整性、可检测显示问题及共享术语词表。2026-10-26新增同次DeepSeek响应的`qualitySignals`旁路自检和绑定原题／候选哈希的具体外部核验意见：数学、证明、高中方法、讲解及难度考查问题均可触发，不能因为未命中词表就忽略。旧7字段教学候选兼容；自检存于workflow，不进入学生题面。自检全pass或旧稿没有自检均不等于独立数学核验通过。规则只定位问题和原句，不执行语义替换、不评数学正误、不强制乘1或禁止所有导数。`teaching-term-review-v3`补充积分、二阶／高阶导数、无穷求和、明确英文方法名及省略`lim`的端点写法；一阶导、有限项求和、普通无穷区间不因此命中。Rust与离线JS共享词表及正负例，课堂范围仍由模型结合实际教材判断。
5. 没有已知问题时不访问Qwen；任一结构、术语、显示、自检或已核实的具体质量意见触发后，使用Qwen3.8 Flash开启思考复核**一次**。结构有效且问题可定位时使用受限补丁：表达只修相应文字；数学、证明或方法问题允许修改所涉解析、答案及必要的相关教学字段，不能只删术语名称或照抄原推导清除问题。逐条返回修订依据；它仍是模型修正说明，不是独立正确性证书。合同绑定题目ID、来源内容哈希、候选哈希和允许字段；旧文不匹配、越界、重复字段或不合法结构使整份补丁失败，不接受部分结果。材料问题、难度档位／要求列表等需超出文字字段范围时，发起前直接选择同一额度内的完整稿合同，不在补丁失败后另调模型兜底。仍不可靠的内容继续待复核，既有已用额度不重置，合格稿不重跑。

   受限范围为完整的教学文字字段，而非句级或公式片段锁定。可修改答案、教学解析、难度依据、考点与现有学生要求的单条文字；不能修改题面、原卷参考、素材、UID、题目身份、难度档位或增删数组元素。模型仍负责理解原题与方法适用性，程序不按关键词决定数学错误或强制选解法。只控制写入范围不能证明替换内容正确，也不保证模型思考更快。发送前继续去重相同稿件与重复建议，题面、完整教学稿、疑点和命中数不截断，原存档不变。
6. 合并后重新检查结构、字段完整性、术语和显示；残留、失败、未解决疑点及缺必要材料继续待复核，不自动再调用Qwen。原始`issues`不因“已处理”而删除。逐条实际核对原题、答案、解析和公式后，教师可将具体参考笔误或不影响该稿使用的观察显式确认为非阻断提醒，并填写依据；未确认意见仍阻断。分类来自这一具体确认，不由词表或模型自评自动决定。原题保真、素材、身份、版本和精确重复等硬性问题不能借此放行。候选内容或来源版本改变后旧确认失效。规则无命中、显示正常、模型高置信或JSON合法都不等于独立数学核验，合格候选仍沿用现有入库确认边界。

首次真实天津卷将整卷来源整理与全部课堂稿放入同一响应，产生`finish_reason=length`、零题被接受。这次失败保留原件与响应；以上分批方案是依据该实际失败调整，不通过加长超时或接受残缺JSON掩盖问题。

## 数据与恢复

来源整理分批保存于`sourceStructuring`，局部结果不放入可审核`questions`。新正式流程`pipelineVersion=indexed_parallel_v2`以紧凑列发送全部真实OCR块，并附实际原页PNG供索引核对；不重复整页Markdown，不发送知识目录。由LLM识别跨页整题、对应原卷答案、明确共享的答案汇总块和非题资料；程序检查所有块均被归属、真实块身份、共享声明及顺序。短题每批最多3题、合计约12000字；解答题默认单题发送，超出单批预算的其它整题也单独发送。单题含原卷参考超过40000字明确失败，不截断原文。转录只附本批原页和相关实际素材，不带全卷或知识目录。旧无图轻量索引的成功断点继续按原审计核验，不把新请求策略追溯写进旧记录。

需要考查信息补充时，沿用显式补充入口的紧凑真实教材目录和UID校验，不发送旧试卷考查任务，不从题型或旧标签补造新关联。新来源转录不携带这一标注目录；旧已完成来源批次中已有的正式关联与元数据保留，按其实际旧请求／响应核对，不因新来源请求格式精简而失效或重跑。

每批沿用索引中的真实题号、固定题目ID及完整原文块，保留学生题面与教师参考素材角色。跨页题不按页面硬切；共用答案汇总块只转录对应题的原答案。非题资料的实际素材也须保留角色依据，不能以分批为由跳过。成功批次、结果哈希及实际请求／响应审计在继续前验证；修改原件、OCR manifest、计划、题目或审计均阻断，不偷偷重新生成。

返回合同逐题列明本批必需的固定身份和原文块字段，遗漏字段的完整JSON也不得作为成功批次。素材清单同时强调实际引用：题图放题面、解析图放真实原卷解析，不能仅写角色而不呈现。表格有实际裁图时优先在原位置保留原图；原图文字与OCR转录不一致时，不改OCR基准、不放宽表格校验，也不猜补数据，用真实裁图保持行列、合并格和原始内容。

每次模型请求前先保存操作身份和发起状态。取消、网络失败或应用退出保留全部已完成批次；显式“重新解析”使用新操作身份，只处理未完成批次，不重跑索引及成功批次。同一操作重放不重复调用，重新打开历史不外呼。恢复复用已有有效OCR，不再次上传或识别。全部批次完成后仍执行整卷题号、素材、表格及身份检查，整体通过才写入可审核题目并开始教学稿生成；局部成功不视为整卷完整或数学正确。

旧版最多3道解答题一批的断点先按原布局和实际审计严格核验。若旧多题解答批失败或中断，用户以新操作显式继续时，仅将未完成后缀拆成单题；已成功前缀的完整批次JSON、索引和题目ID保持。旧未完成批次及调用记录存入`repartitionHistory`，新布局以版本、范围哈希、连续完整覆盖及预算检查绑定。全部成功的旧布局不迁移，当前操作失败后不自行循环或增加超时。

- 原卷`answer`、`solution`和小问字段保持来源含义；`teachingWorkflow`单独保存初稿、触发证据、复核候选、最终候选和状态。
- 告警处置单独保存在`reviewDispositions`，保留原`issues`及完整命中记录；按确切意见索引、原文哈希、来源和候选哈希绑定具体确认、核对依据与核对身份。仅过滤已确认的模型意见作为非阻断提醒，不清除术语、显示、内容不完整或原题硬性阻断。正常教师操作记录为教师核对；本次显式维护的用户授权代理核对记录为`user_authorized_agent_review`／`codex`，不能冒称教师已审核。
- 人工教学文字修订与模型受限补丁分别记录。人工保存须提交完整字段原值和新值、当前修订、来源及候选哈希；仅写入获准的教学文字字段，原模型稿和源字段不覆写。保留实际补丁和变更前状态，重放按原操作身份幂等；失效版本或未授权字段整次失败。任何候选修改都会清除该旧版本的告警确认，须对新候选重新核对。发布时校验补丁链与确认绑定，不能把未经核对的修订标为原模型输出。
- 生成、复核分别保存实际构造请求的无认证头审计、提示词／正文哈希、响应和已绑定源内容哈希。带审计路径的来源／教学生成／复核请求另存逐次`.transport.json`，只含请求字节、预算、思考开关、总时限、响应头／正文阶段耗时、HTTP状态及结果码；HTTP前独占创建、阶段更新、失败与取消均保存，不记录认证头或正文。密钥不写日志；未采集内容明确未知，不编造思考轨迹。
- 每批生成及每题一次复核的发起状态在HTTP前落盘。取消或异常保留原件和完成结果；显式继续只执行尚未发起的工作，已发起未保存结果标记中断，不偷偷再次花费。
- 用户明确指定修复失败题时，开发维护入口可按精确题目清单、源版本、记录修订及新操作身份执行一次失败恢复。只接受没有有效最终稿的生成失败／中断题，逐题发送，保留旧审计并累加生成次数；不重置已用Qwen额度，不处理其他题，不构成自动循环。相同操作重放不再访问模型。已拆成单题的显式失败恢复最多等待300秒；常规生成和整卷来源整理仍为120秒。
- 2026-10-24传输审计证实，当前17次单题Qwen复核有11次在约120秒等待响应头时终止；历史同provider／模型开启思考有147～282秒成功的单题请求。因此，仅千问AI平台精确`qwen3.8-flash`且`originalMaterial.questionId`非空、没有`questions`批量键的教学复核合同使用300秒**整次HTTP总预算**；其余任务、provider和无效／批量合同沿用原限。不改变思考参数或输出预算，不隐式重试，不重置旧额度。300秒不保证成功，也不用于扩大整卷输入。详见[规则与超时排查](../review/teaching-trigger-timeout-2026-10-24.md)。
- 教学稿使用独立来源版本绑定。编辑原题或原卷参考后旧稿失效，前端不能伪造复核通过状态。
- 发布时合格教学稿进入独立`teachingAnalysis`，原卷参考不被覆盖；人工核对原题后仍允许沿用原有人工入库权，但不合格稿保留标记、不能冒称合格教学解析。已有题库、冻结成卷及旧导入记录不批量改写。

## 模型与界面

### 2026-10-25：来源失败的精确恢复

用户要求修复十卷试跑中四卷的来源阻断，复用已保存OCR和成功结果，不重复生成已有候选。以下是来源完整性与恢复实现，不改变教学稿的DeepSeek生成／Qwen命中后复核一次及入库确认边界。

- 本地模型、角色与OCR配置仍在导入前检查；服务商在线模型列表在OCR及页数验证结果保存后、实际新模型工作前检查。列表接口临时失败时，已保存OCR仍可继续使用，不降级静态模型名单，也不改变服务商或密钥。
- PDF检查增加非常窄的兼容读取：仅对最终`startxref`指向的空经典交叉引用节，在内存检查副本中补零条目分节，保留最新trailer、已有对象与全部对象偏移。继续执行加密、页数与OCR返回页数检查；上传给OCR的原PDF字节不改写，`pdfInspection`另存检查方式和哈希。不将它作为通用损坏PDF修复或忽略加密的入口。
- 短卷若已有完整且实际HTTP 200、`finish_reason=stop`的来源响应，仅因题号覆盖检查失败，可在用户显式继续时先本地重放。重放校验原件、OCR、旧attempt、实际请求／响应、原context与素材身份；重新执行当前完整拆题校验和同次来源意见处理。旧失败attempt不改成成功请求，新`sourceResponseReplays`只追加独立操作及结果，不伪造新的HTTP或清除原失败。绑定不符、截断或重放仍失败时停止，不自动再请求模型。
- 来源索引若已因题号身份校验失败，显式新操作可附已校验OCR保存的全部原页PNG重新核定索引；实际图片及原失败attempt哈希进入审计。首次索引和已有成功索引不扩大请求，不重复处理成功批次。缺少唯一原页或模型不支持实际看图时阻断；不按顺序补号，不改写OCR，原页仍不能确认的题号继续待核。
- 长卷在所有成功来源批次之外另存`sourceMaterialSupplement`，只补核未覆盖的保留素材，原批次、题文、答案解析及知识身份不重生成。补核实际投递孤立图片、同页原图、已有图与已保存题目的对应信息，由模型明确题目、角色、真实原文块和呈现位置；程序验证精确身份、范围、实际投递像素与请求／响应审计。不能因图片缺少布局关联就删图、猜角色或放宽整卷素材覆盖。
- 模型建议另一图可代表该素材时，只有同题、同角色、代表图确已呈现且程序核对精确像素包含，才能避免重复显示；近似相似或有损压缩差异不作为等同证明。缺少严格证据时保留两张原图，并向受影响题的`sourceIssues`、`reviewIssues`写入具体阻断意见；不把可定位到单题的问题泛化为全卷失败。补核无法可靠归属时保留失败和实际响应，不能通过置信声明忽略缺图。
- 素材补核若已取得完整HTTP 200且正常结束的回复，但本地合并失败，显式继续先重放该实际回复，不重新请求模型。历史缓存缺少可选的`sourceIssues`时仅初始化空数组，非法类型仍拒绝；原失败attempt和审计原样保留，另记`local_validation_replay`及原attempt哈希。重放仍失败时立即保留失败，不落入新请求分支。
- 发布时从原成功批次与实际素材补核审计重放派生素材结果，继续检查完整覆盖。合并只允许追加经核对的素材引用、角色与具体意见；不因来源恢复而重置已用教学复核额度，不覆盖既有教学候选。历史阅读及重放核验不访问OCR或模型。

上述来源恢复不证明数学正确、课堂可用或正式教师已核对；真实四卷恢复效果与独立抽查另存本轮报告。

角色使用本机已保存的DeepSeek与Qwen独立配置，各自请求对应provider的`/models`。不会改变活动配置或思考偏好，不同provider不能共用密钥；缺少或存在歧义时明确失败。正式应用不读取维护脚本使用的`~/.agent.env`。

导入后台新增“生成课堂教学稿”和“复核课堂表达”进度。审核页将AI教学稿与原卷解析分别展示，待复核原因可见；详细解析、难度依据、考点及对学生的要求按需展开。读取页面不外呼，不新增常驻逐题模型初审按钮。

审核页逐条显示教学稿意见的“阻断／已核对提醒”及其依据。非阻断确认不是整题一键忽略：教师须对当前版本明确核对原题、答案、解析和公式，逐条填写为何不影响使用。教学文字修改显示所选字段的原稿与待保存内容，明确保存后才由Rust校验版本与允许字段；取消不落盘。已发布题、正在处理的导入或存在原题硬性问题时不提供绕过入口。界面上的提醒分级不会修改原卷、旧成卷或历史模型响应。

当前自动显示检查覆盖控制字符、字面换行及公式分隔符；仍须通过真实富文本渲染和抽样原卷核对评估公式、图片与数学质量。不能据此声称所有LaTeX或所有超纲表达已被检测。

Paddle返回的整页预览与布局可使用不同像素尺度。仅在宽高比误差符合整数像素取整、且原布局框完整合法时，保存原坐标并记录缩放后的实际像素框；比例异常和越界仍阻断。官方结果下载节点只允许固定HTTPS主机及受限TUN合成地址例外，不放开真实私网、任意子域或跳转。旧manifest不通过删问题标记来“修复”，需在用户明确恢复时重建或重新识别失败阶段。
