## 行为

1. 用[精简主提示词](math-teaching-analysis-prompt.md)生成完整教学JSON，独立保存实际请求与原响应。
2. 只扫描新生成的 `answer`、`difficultyAssessment.basis`、`teachingSolution`、`teachingFocus.examFocus`、每条 `studentRequirements`。不扫描题干、原参考、`issues`、知识UID或其它技术字段。
3. 没有命中时不复核；有命中时，将原材料、首稿和实际命中记录发送给复核提示词。附加指令要求结合原句及实际问题控制修改范围，不提供逐题纠错答案或强制解法。表达或显示问题优先局部修正；确需改方法或补证明时核算受影响的推导，发现具体数学错误才扩展到相关结论。完整返回保留内容和修改内容，不因返回全部字段就重新求解或全部重写。综合入口与普通导入共用的附加指令另明确材料核对范围，干扰选项、旧参考错误和本次未交付图片不混称题面缺陷。
4. 对复核稿再次扫描并保存剩余记录，最多调用一次语义复核。残留术语、新增术语或合理保留都保持可见，不无限循环。

正常执行为N次生成加H次命中后复核。程序不根据解法长度、次数、难度、方法类别或正确性触发复核；JSON、身份和类型校验仍是程序职责。

## 词典及数学边界

词典版本 `teaching-term-review-v3`，称为“需要检查的术语”，不是违规词典。每条含稳定ID、类别、字面别名／固定匹配器及具体检查建议。资源仅作数据读取，不运行词典里的代码或动态正则。

- `classroom`：范数、目标式、封闭性、同余等课堂表达提醒。
- `special_tool`：洛必达、泰勒、微分中值定理等工具的已学范围提醒。
- `context`：标准化、线性表示、Φ、极限记号等依语境判断的提示。

裸 `≡` 不单独认定同余，须有同句的同余语境；柯西不等式与柯西中值定理分别使用独立词条；不扫描“上解／下解”裸子串，以免误报“以上解法”等普通句子。仍可能存在语境误触发或词表遗漏，不能用是否命中判定课标合规。

2026-10-23补充：v1只收录柯西中值定理，且负例测试显式排除了普通柯西不等式，导致第4题未触发。v2新增柯西不等式及常见中英文别名，复核建议要求用已学不等式、平方非负或具体代数推导说明所用关系，不能仅删定理名称。旧9题执行仍保留v1快照和原记录。第4题一次实际复核由1处命中变为0处，补出了平方非负证明，但仍保留分类，详见[定向复核记录](../review/teaching-term-cauchy-sample4-2026-10-23.md)。

命中记录保存词条ID、实际匹配文字、字段路径、原文UTF-16起止下标、附近原句和检查建议，可用原字段的 `slice(start,end)` 对照。符号只定位，不归一化或替换原文。

2026-10-24补充：v3新增积分用语／符号、二阶与高阶导数记号、无穷求和、明确英文方法名、没有lim的单侧／无穷端点简写，并补齐已约定的“线性组合”。Rust与JS共享15组正负例；普通一阶导、有限求和、无穷区间、正常函数加法与单独“线性”不因这些规则触发。它们只提示结合本题教材与已学范围复核，不将高中选修中的微积分概念一概称为大学专属；空间距离公式是否缺少讲解等语义问题仍须独立审计。只读重扫与超时修复依据见[本次记录](../review/teaching-trigger-timeout-2026-10-24.md)。

复核不得把单射等同零点唯一、把所有范数都改成向量模、把拐点改成切线斜率变化点，或把下界直接改成最小值。需要时重写数学论证；必要且范围适合的术语可以解释后保留。

## 输出及失败

教学JSON继续沿用 `teachingFocusSchemaVersion:2`，不增加knowledgePoints列表。管线状态和审计放在外层文件，不注入教学稿或原参考的 `issues`。

- `no_term_hits`：未发现已配置词条，未调用复核。
- `rewritten_no_term_hits`：已复核，未再发现已配置词条。
- `remaining_term_hits`：已复核，仍有词条可供查看。
- `generation_failed`／`review_failed`：明确失败，不伪造最终稿。复核失败仍保留首稿和实际响应，`finalResult`为空，不静默采用首稿冒充已复核结果。

这些状态不表示数学正确、学生能理解、教师审核或可自动发布。`textComplete`仅表示必需文字字段非空，不验证答案或证明；模型报告的缺材料及参考冲突单独保留。当前库写入仍有正式知识关联、版本与哈希等独立条件，本工具没有调用写入入口。

## 实现与记录

入口：`scripts/run-teaching-term-pipeline.mjs`。核心扫描和调度可注入模型回调隔离测试；生成使用本机已保存的DeepSeek Flash/high配置。命中后懒加载Qwen：优先唯一匹配的已保存思考on配置，缺少匹配项时读取用户授权的离线`~/.agent.env`中的`QWEN_API_KEY`；歧义或解密失败直接保留失败，不跨凭据尝试。两个服务商分别调用自己的`/models`，不提供静态模型列表兜底，不切换应用当前配置。

Windows DPAPI密文通过隐藏PowerShell进程stdin传递，密钥只在内存用于认证，不在命令参数、环境变量或审计里传递。原请求在外呼前写入，原响应去除隐藏思考文字后保留正文、finish_reason、用量和耗时。模型失败、输出截断或身份不匹配不作为成功。

输出目录必须是新目录，输入/请求/响应、词典快照及源码哈希分别保存；不读取个人数据库，不修改模型设置或题库。测试为隔离模拟，不冒称真实教师案例。实际9题结果另见执行报告，不能由词条减少外推正确性提升或未见题效果。

## 输出格式失败的定向复核（2026-10-23）

用户进一步授权：JSON／字段结构失败可额外复核一次，通过后保存独立教学稿；仍有问题或术语残留则标记。此授权用于显式离线维护，不改变普通导入和查看时的调用边界。

`--recover-format` 显式开启，默认关闭。仅主生成响应完整结束、实际正文已保存而 JSON／身份／结构校验失败时触发，将原题、失败原文及错误记录交给模型独立核算并重新输出完整对象。它不是字符替换或容错 JSON 解析；身份检查仍严格执行，正常网络失败、超时、截断及术语复核失败不自动进入。格式复核后不再追加术语调用或继续修复循环。

复核稿再次执行结构、必需文字、已配置术语和控制字符／公式分隔符检查；可由维护调用方附加 LaTeX 渲染检查。`recoveredResult` 保存结构合法的稿件，只有无已知标记时才有 `finalResult`。`needs_review` 与 `recovery_failed` 都不是数学错误的同义词：前者可能只有措辞残留，后者不能假装已拿到完整稿。自动检查不证明数学正确。

独立审计可以另记录已发现的数学或教学问题，不能冒充模型自己报告的疑点。用户明确要求入库后，写入清单保留未修改的 `modelResult`、实际请求响应和维护标记来源；为现有界面展示待复核原因，可在保存副本的 `issues` 中追加明确标为“维护复核标记”的原因，原模型 JSON 不变。术语命中属于待检查表达，不宣称必然超纲或数学错误。

再次格式失败时不将可读片段或旧稿伪装成新复核稿。`teaching-apply` 的显式 `markOnly:true` 条目只给当前已校验教学稿追加标记与独立维护历史，保留其解答、难度、生成时间、模型及请求溯源。正常替换与仅标记都校验原题／参考版本和当前索引哈希，以事务保存前后审计；失败整体回滚。读取历史与成卷冻结内容不随维护刷新。
