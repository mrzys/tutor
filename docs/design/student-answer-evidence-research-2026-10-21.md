# 学情基础功能调研：学生答卷与作答证据

调研日期：2026-10-21。状态：研究结论与待评审设计，未实施功能、修改用户数据或进行真实教师试用。

后续用户明确采用“选择学生 → 选择试卷／填写练习名称 → 上传答卷 → LLM 批改”，并确认实施。
当前第一版范围以 [ADR-0007](../adr/0007-student-answer-grading.md) 为准：包含后台 AI 批改、结果历史和按需教师修正。
下文保留调研过程，暂缓 AI 批改的建议已被取代，不能作为当前实现边界。

## 结论

第一版建议做“学生答卷档案＋可选轻量批改”。先可靠记录学生交回了什么，再积累教师明确记录的逐题结果。
上一稿把知识点掌握状态维护放得过早；本次建议将它后移，学生详情默认展示答卷记录。

最低交付闭环：选择学生 → 选择本机成卷或填写外部练习名称 → 上传 PDF／照片 → 预览确认 → 保存归档。
归档后可以立即离开，按需再记录分数、对错和评语。不要求模型配置、OCR、逐题裁切、答案补全或全部批改。

答卷档案是以后学情的证据基础，本身不等于已经完成诊断、掌握度估计或教学有效性验证。

## 第一版做什么

| 功能 | 建议范围 | 明确边界 |
| --- | --- | --- |
| 学生管理 | 姓名／昵称、可选年级、搜索、编辑、归档 | 不先建班级、家长账号、画像问卷 |
| 答卷归档 | 一名学生的一份 PDF 或多张 JPEG／PNG；原件保存、连续预览、页序和旋转 | 已归档即可离开，不依赖任何模型配置 |
| 关联试卷 | 优先选择本机已确认成卷；也允许外部练习以名称归档 | 外部答卷不强制先导入题库，不猜测对应题目 |
| 答卷备注 | 可选作答日期、练习名称、简短教师备注 | 上传时间不冒充实际作答时间；不知道日期可留空 |
| 轻量批改 | 对关联本机成卷，按题／小问可选记录对错、得分、短评 | 不强制整卷录完；不要求重录学生整段手写过程 |
| 补充与重做 | 同次答卷追加漏页／清晰照片；订正和再次独立作答分别关联历史 | 不覆盖第一次原件与结果，不把同题订正当陌生题表现 |
| 导出与备份 | 导出原答卷及记录摘要；备份包含个人库与实际附件 | 只有数据库的备份不算完整答卷备份 |

如果第一批范围必须进一步压缩，先交付“学生＋答卷原件＋关联成卷＋历史查看”，轻量批改作为紧接的一小步。
长期数据关系从第一版预留，不必同时建自动分析系统。

## 页面与最短路径

侧栏在“导入试卷”下放置 `Users` 图标和“学生管理”。左侧学生列表，右侧学生详情，默认“答卷记录”。
另一页为“学习备注”，保留教师自由备注；不默认展示空洞的能力雷达或掌握度百分比。

入口有两处，汇入同一条流程：

1. 学生管理 → 某学生 → “记录答卷”，学生已带入，选择成卷或外部练习名称。
2. 成卷页 → “记录答卷”，试卷已带入，默认本卷关联学生，也允许教师明确选择另一学生。

归档流程只做：添加文件 → 检查预览、页序和归属 → “保存答卷”。日期、总评和批改不是必填项。
保存成功显示明确反馈，记录进入学生时间线；失败保留已选择文件和输入，支持重试。

答卷详情使用可用屏幕空间：左侧原件预览与缩略页，右侧为关联试卷的题号／小问及可选结果。
需要时切换“原试卷”参考；未关联试卷时只展示答卷和备注，不制造一组不存在的题目。
教师点击“记录结果”后才展开批改区。第一版不实现完整手写批注、PDF编辑器和复杂rubric编辑器。
老师已在纸面批过，也可以直接上传含批注的扫描件，不要求再次逐题录入才能归档。

## 一条记录究竟代表什么

必须把业务中的“作答记录”和技术上的“文件版本”区分开。

| 操作 | 保存方式 |
| --- | --- |
| 第一次录入看到的答卷 | 新建记录；未确认是否首次实际作答时只称“答卷记录”，不猜真实次数 |
| 漏拍一页，后来补传 | 在同一记录追加附件／页面，不增加独立作答次数 |
| 换一张更清晰的照片 | 保存新的附件版本，旧原件可追溯；不增加作答次数 |
| 补传老师已批改稿 | 同一记录追加“批改稿”素材角色，保留学生原件 |
| 看过讲解后订正 | 新建关联的“订正”记录，保留原答卷；不是一次独立测量 |
| 重新独立做一遍 | 新建“重做”记录并关联前次，可选记录是否有提示 |
| 修改录错的得分 | 产生批改修订，不新建作答，不覆盖原件 |

多人材料混在一个 PDF 的自动拆分不进首版；由教师先拆为单学生文件，避免归属猜错后污染全部学情。

## 状态和分数的基本规则

界面区分以下状态。只存原件是一种正常用法，不生成必须处理的待办：

- 已归档：没有逐题结果或手工总评。
- 已录入总评：教师仅录整卷分数，不能据此宣称逐题已完成。
- 部分记录：已有部分题／小问的明确结果；“暂无法判断”和未记录仍保留，不标整卷完成。
- 已记录结果：关联试卷的全部记录单元都有教师明确结果；定性练习不要求数值分数。

未关联外部练习没有可靠题目总数时，不显示虚构的完成比例。按题计数和按小问计数须注明口径，不能混用。
技术上分开三个维度，避免以后不得不从一个模糊status字段逆推：

| 维度 | 可表达的信息 |
| --- | --- |
| 材料情况 | 正常、缺页、看不清；保留具体说明 |
| 作答情况 | 未知、有作答、教师确认未作答 |
| 批改情况 | 未录入、部分录入、教师确认已记录 |

逐题结果可以选择“正确／部分正确／错误／未作答／暂无法判断”，默认未记录。
其中“未作答”必须来自教师确认，不来自 OCR 空串；分数默认为空，不默认为0。
未作答与得零分也分开：前者描述观察，后者是评分决定。

第一版无需显示正确率。若计算对错统计，只使用教师明确判定的结果；“暂无法判断”、未记录、看不清不得进入对错分母。
教师确认未作答时保留相应状态，是否给0分由评分决定，不自动改为“错误”。
部分批改显示“已记录6／10题”，不能把另外4题算错；若还有无法判断项，单独显示其数量。
教师只填整卷总分时，保存“手工总评”，不把分数自动分摊到每题；逐题小计与手工总评分别保留。
如二者不一致，提示核对，不静默覆盖。大题和小问不双重累计。

当前应用不计分练习的题位分数会保存为0，这不能解释为答卷满分0分；此类答卷默认只记录定性结果与备注。
需要计分时教师明确设置评分方案，评分依据随结果保存，不改写冻结成卷。

## 保存结构：够简单，也能继续演进

以下为建议的领域结构，不是已实现表或承诺实现整套教育互操作标准。

| 对象 | 第一版至少保留 |
| --- | --- |
| 学生 | 稳定studentId、昵称、可选年级、归档状态 |
| 答卷记录 | recordId、studentId、试卷来源、本机paperId及快照哈希或外部练习名、可选作答日期、真实录入时间、记录类型、前次记录引用 |
| 附件与页面 | artifactId、素材角色、原文件名、类型、大小、内容哈希、本地相对路径、页面顺序和展示旋转 |
| 教师结果 | 所属答卷、题位slotId、可选partId、结果、可空得分／满分、短评、修订号及记录时间 |
| 页面关联 | 题位／小问与“附件ID＋原文件页码”的可选关联，一题可多页，一页可多题 |

本机试卷必须关联不可变成卷及其题位，不仅关联题库questionId或当前题号：同一道题可在不同卷和不同次作答中出现。
题号和小问标题用于显示，稳定身份用于保存。页码定位第一版可选，不强制裁出每一道题才能存档。
外部练习暂没有题位映射也可以保存原件，后续人工关联不能偷偷替换教师原先上传的题目版本。

学生答卷、结果、备注全部保存在个人数据与独立答卷目录，不进入question-bank.sqlite或共享题图。
原件保留字节和哈希，旋转、裁剪及识别另存派生信息。归档学生或从历史列表隐藏成卷不能让答卷引用失效。
新增学生记录删除和附件清理必须单独处理引用关系，不沿用“删列表就删除原卷／所有附件”的行为。

本机保存不代表可以只备份SQLite；导出与恢复必须覆盖附件、记录、快照身份与哈希。
文件写入与记录提交要防半成功，重试幂等，缺失或损坏明确提示，不能显示为“学生空白作答”。

- `desktop/src/PdfPreview.tsx` 已有连续多页、缩放适配及取消清理，可复用预览机制；它目前只接受paperId／importId，答卷要有自己绑定记录身份的读取适配。
- `desktop/src-tauri/src/imports.rs` 的原件保存、哈希与路径校验可以提取复用，但不能直接调用import_prepare处理答卷。
  该入口要配置模型／OCR并服务题库入库，目的与答卷归档不同。建议新增独立答卷IPC和文件读取边界。
- 现有学生标签仍用于本地归属，第一版保存答卷不向模型或OCR发送学生材料，也不新增登录、学生端或云端服务。

## 关联学生组卷：第一版同步到哪一步

第一版关联后仅展示最近答卷摘要及“查看答卷”，让教师容易找回已有记录，不自动改变组卷参数。
后续再提供“后续巩固”与“参考这些记录”：教师明确选择已记录的题目及结果后，才可形成组卷建议，进入现有需求确认流程。
仅传递教师选定的题目及教学结果，不发送学生姓名、学生ID或自由备注。未记录逐题结果时不生成薄弱知识点。
不因上传答卷或一道题做错就覆盖已学范围、降低目标难度、增加题量或改写教师正文。

如果同题涉及多个知识点，错误先挂在本次题位／小问；不自动把该题所有主考和解法依赖都标为学生不会。
后续再研究基于多次、不同条件的作品形成学情建议，原始记录、教师判断和模型建议仍分别保存。

## 后移能力与演进

1. 首批：学生管理、答卷归档／查看／补充、成卷关联、备份导出；可选轻量结果与短评。
2. 后续：便捷题页关联、教师确认的错题巩固、选取记录参与组卷；不把未批改结果纳入统计。
3. 再后续：可取消、可重试的OCR辅助定位与转录，以及模型建议；失败不影响原件访问，确认与建议分开。
4. 有真实数据和教师反馈后，才讨论稳定的知识点状态、跨次趋势与个性化教学策略。

第一版不做自动掌握率、能力雷达、成绩预测、自动教学计划、班级排名、多人自动拆卷和复杂自动批改。

## 验收与真实试用计划

实现后的隔离回归至少覆盖：

- 无LLM／OCR配置，仍能保存和查看答卷；没有原卷答案解析也不阻断归档。
- 一份PDF及多张照片正确排序、旋转、重开；保存后原件哈希一致。
- 选择学生、切换试卷归属显式确认；外部练习无需先入题库。
- 补传、换清晰照片、添加批改稿均不增加重做次数；订正和重做不覆盖原次记录。
- 未批改不算错误；看不清不算未作答；没有分值不伪造满分或正确率。
- 部分批改、只记总分、小问计分和批改修订的汇总正确。
- 隐藏历史成卷或归档学生不丢答卷；文件丢失、损坏、存储失败与备份恢复可见且可恢复。
- 冻结试卷与题库后续修改互不影响；没有人为记录时不自动改学生掌握状态。

真实试用应分别观察：私教录入本机练习、学校外部卷、已批改照片三种任务。
衡量是否能不经帮助保存并找回答卷、归属／页序错误、重复输入、批改用时，以及教师是否愿意复用记录。
具体耗时目标在原型后由真实使用测定；本次未进行教师访谈、可用性实验或教学效果评估。
