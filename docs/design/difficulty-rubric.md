# 数学题五档难度口径

日期：2026-10-20。版本：`content-demand-v1`。这是本产品的内容判断标准，尚未经过真实学生作答数据标定，不是国家考试或 PISA 等级。

## 参照条件与用途

以对应学段、已学本题所需知识、独立作答为参照，保留题面给出的提示和前问支架。判断的是题目本身要求的挑战；某名学生是否学过、熟练程度如何另属学情，不由此推断。

- 教师设置的**难度要求**用于表达想选什么样的题。
- 题库的**内容估计**描述现有题目，不能从教师目标或规划理由反推。
- 基于具体学生群体答卷统计的难度是另一类证据；目前没有这些数据，不输出预测正确率或精确难度系数。

## 五档标准

| 档位 | 主要判断 | 与相邻档的区别 |
| --- | --- | --- |
| 基础 | 直接辨认概念，或按明确方法代入、运算 | 核心关系与解法入口直接可见 |
| 基础偏中等 | 方法常规明确，增加一次简单变形、表示转换或条件检查 | 多一层处理，但无需独立设计策略或复杂分类 |
| 中等 | 自行选择常见方法，连接多个常规推理环节，或完成常见分类讨论 | 路线未直接给出，但仍是熟悉题型 |
| 中等偏较难 | 常规方法上有一个实质性关口：隐含条件、参数边界、关键构造或跨表示联系 | 需发现关键关系、检查论证完整性，不能仅靠延长常规运算 |
| 较难 | 多个相互依赖的实质性关口，需要策略设计、综合论证或推广 | 掌握所需知识后仍需较强的独立组织与迁移能力 |

两个过渡档分别表示“**基础方法多一层处理**”和“**常规综合上多一个关键关口**”。不通过给步数、知识点数量或计算量加分来机械切档。

## 评估步骤

1. 确认主考内容及完成整题所需知识；信息不足时保持未评估。
2. 找到符合已学边界的最简合理完整解法；不因使用了生僻解法而提高等级。
3. 看四个维度：方法是否直接可见，推理与表示转换跨度，条件／分类／边界分析，知识和方法的综合程度。
4. 写清决定难度的关键关口，再选择最符合的档位。边界不清时说明相邻档的差异，不制造小数分数或置信度。

多小问题按题面提示下完成整题必经的关键关口判断；前一问给出结论后，后一问不再按完全无提示评估。若只有最后一问较难，应说明“前问基础，末问存在某关键关口”，而非暗示每一问都同难度。

题干长、知识点多、计算繁琐、题型为多选或要求证明，都不足以单独决定难度。缺图、歧义、错误答案及原文丢失属于内容质量问题，不能归入较难。

## 同一知识领域的示意

以下只是用于解释分档的假设任务，并非已评估的真实题库题或教师案例；具体等级仍取决于完整题面、已学前提及提示。

| 档位 | 集合内容的示意任务 |
| --- | --- |
| 基础 | 从直接给出的有限集合判断某元素是否属于它 |
| 基础偏中等 | 先完成一次简单不等式变形，再判断给定数是否属于集合 |
| 中等 | 自行求常见条件定义的集合再做交并运算，或完成常见单参数区间的空集、端点分类 |
| 中等偏较难 | 在常规集合运算之外，还需发现隐含的量词约束或非直接的参数关系，并组织必要性、充分性的论证 |
| 较难 | 多个参数与量词条件相互制约，需组织完整分类并证明必要性、充分性 |

含参数、空集或端点不直接决定档位。常见单参数区间分类通常属于中等；升到中等偏较难时，依据必须指出额外的实质性关口。

## 当前落地边界

可执行口径保存在 `desktop/resources/difficulty-rubric.json`，难度选择说明、Rust 规划、试卷导入和显式题库重标共用。规划仍须教师确认；教师明确等级不能被模型擅自覆盖。

2026-10-20 后续更新：用户明确授权对现有题目同时重标难度、主考知识点和逐解法依赖。重标通过显式可恢复任务执行，保留旧标注与原始响应，按精确版本更新后续组卷索引；不改写题面、来源、数学审核状态、已有草稿及成卷。未知或失败保留具体原因，失败题不以默认档替代。

新导入保存 `difficultyAssessment: {level, basis, rubricVersion}`，发布后索引为 `difficultyLevel`、`difficultyBasis`、`difficultyRubricVersion`，不生成精确数值难度。非空档位必须有具体依据；无法判断则 `level: null`。审核页可更改等级及依据或清除，仍须独立完成题目内容核对。旧记录缺字段保持未评估，可继续审核；查看历史不调用模型。

系统不自动把旧三档细分成五档，也未新增学生作答标定能力。重新标注并不等于独立数学验算，原教师资料的生成来源和审核范围继续保留。

## 参考与区别

[OECD PISA 2022 数学框架](https://www.oecd.org/en/publications/pisa-2022-assessment-and-analytical-framework_dfe0bf9c-en/full-report/component-3.html)区分数学推理、问题解决过程及不同数学要求；这里据此选择观察维度，没有把 PISA 等级映射成本产品五档。

[NAEP 经典题目分析](https://nces.ed.gov/nationsreportcard/tdw/analysis/initial_classical.aspx)基于实际作答统计难度与区分度。本文的五档内容估计不替代这种测量。
