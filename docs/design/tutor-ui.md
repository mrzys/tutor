# Tutor UI 应用说明

2026-10-23 模型目录调整：新增独立的千问AI平台。配置顺序为服务商 → 此配置的 API Key → 显式获取该服务商模型列表 → 搜索并选择真实模型 → 已知能力设置。列表失败原位重试，不显示静态备选；已保存原模型可离线保留。切换服务商或密钥、取消或重开编辑器后，旧响应不得回填。获取列表不等于修改配置，完成编辑及最终保存仍分别执行；未知模型不展示猜测的思考开关或强度。

同日思考设置补充：千问AI平台仅已验证的 `qwen3.8-flash` 显示关闭／开启思考，不提供强度档位；能力元数据不替代服务商实际模型列表，未显式设置思考的旧配置保留原请求策略。

2026-10-22 规划数量核对：模型返回的题位结构、任务身份及分值有效但各题型数量与已确认需求不一致时，保留原需求和原规划进入题位页，逐型列出原定与当前数量，并给出增删或调整题型的建议。教师显式编辑后实时核对；未修正差异前不能开始选题，后端继续严格校验，不静默补删题位或重分已有分值。

开发者日志分别展示请求总耗时、模型调用耗时和实际阶段耗时；这些区间可能重叠，不加总冒充流程耗时。新阶段用单调时钟计时，失败或取消保留阶段终止状态；旧日志仅在起止事件可唯一配对时按记录时间推算并标明来源，缺失证据保持未知。视觉停留不计入后端执行耗时。

2026-10-22 选题交互调整：题位的规划说明直接显示；考查任务、说明、目标及模型建议中的公式统一由既有富文本组件排版，产品难度名称使用共享五档中文标签，内部枚举、原始日志与已存文本不翻译或改写。采用安排后进入独立选题进度页，按后端实际执行的读取条件与题库、比较候选、生成并保存草稿三个阶段展示；快速阶段保留最短视觉停留，不推测百分比。失败或取消保留已确认规划，保存成功后的视觉停留被停止时显示“草稿已保存”，由用户打开成果，不伪报取消落盘。

开发者日志默认隐藏，可在设置的本地数据页显式启用并持久保留；环境变量或启动参数强制状态优先。开启后选题独立进度页同样显示右下角入口，关闭停止正文采集与读取，已有数据不删除。

2026-10-22 输出调整：学生卷和教师卷的整卷预览及新生成 PDF 跳过缺题位，按实际题目连续编号，题量、题型小计和分值合计只统计已展示题目。编辑草稿和成卷确认仍显示原缺题及差异，冻结数据和旧 PDF 不改写。

## 视觉与组件

- 白色画布、黑色主行动、灰阶正文；状态色仅表达明确的成功、失败、警告和焦点。
- 正文采用 `#525252`，次要说明与占位文字采用 `#737373`；中文字体显式包含 PingFang SC、Microsoft YaHei，最小字号13px。
- 按钮、单行输入和选择控件采用胶囊；多行输入按具体组件规范使用12px圆角。容器12px，下拉面板8px，行内代码6px。
- 使用边框和留白表达层级；按钮、链接等非输入控件的键盘焦点使用2px实心 `#3b82f6` outline及2px offset。
- 2026-10-21 用户明确要求模型服务商品牌图标沿用官方原色。模型配置按厂商分组后展示具体模型，编辑按厂商 → 模型 → 该模型支持的思考设置展开；已保存正在使用项与未保存编辑分别显示。配置名称作为可展开项，不能盖过厂商和模型身份。没有多档强度的模型只显示思考开关；旧配置缺项明确显示沿用原设置，不自动更改请求行为。
- 同日后续调整：新增模型配置从空白服务商开始，未完成的表单不进入配置列表；新增与编辑使用独立表单，提供明确的完成和取消操作，配置行显示编辑与删除。未保存输入保留，整页显式保存后才生效。题库列表仅保留题型和难度，点击题面打开右侧详情；加入组卷篮独立操作。筛选值由选择框自身展示，不重复显示条件标签，最右侧提供重置筛选，保留当前目录与组卷篮。去掉重复计数和操作教学文案，失败、缺口、待确认修改和必要的数据边界仍须明确反馈。
- 2026-10-22 用户进一步要求：题目详情抽屉先完整显示题面，再显示考查信息与来源，不折叠题目。列表来源紧接首段题干同行展示，题型与难度放在题目右上方，不另占来源标题行；题型使用中性胶囊，难度使用共享语义色区分五档（绿、青、蓝、琥珀、玫红），未评估用灰色。窄屏自然换行，不覆盖题干；始终保留档位文字，不靠颜色单独传达等级，不影响题库标注或试卷输出。桌面加入组卷篮在鼠标悬浮或键盘聚焦时替换同一区域的标签，详情与加篮的键盘入口互不遮挡；触控在顶部同时展示标签和加篮操作。不预留底部操作空行，不因操作显示或选中改变题目高度。普通行内公式完整排版，只有实际超出可用行宽的公式提供局部横向滚动，避免给每个分式套用滚动框。
- 输入框与选择控件统一采用灰阶反馈：鼠标或触控聚焦时仅将原有边框加深至 `--field-focus-color`；Tab 导航聚焦时增加同色2px内侧轮廓，失焦恢复原边框，不改变布局。搜索、密码及组卷等组合输入框仅由外框显示反馈；错误输入保留错误色，强制颜色模式沿用系统焦点色。
- 来源示例中的11px扩展名标签统一提升为13px；需要阅读的占位符不采用 `--faint`。
- 不引入营销首页、定价深色卡、Download 导航或 llama 装饰。Tutor 的主行动随组卷步骤变化，工作区卡片保持白底。
- Lucide 使用具名导入、描边图标和 `currentColor`；图标按钮有可读名称，触控目标至少44px。数学公式维持 KaTeX 的数学排版，不将中文正文限制误用于公式字形。
- 保留键盘操作、可见焦点、加载与禁用状态、减少动态效果偏好。长内容可以局部滚动，移动端不产生整页横向溢出。

## 页面与反馈

| 页面 | 主要任务 | 必须可见的反馈 |
| --- | --- | --- |
| 教学需求 | 自然语言输入，确认范围、已学边界、教学目标与规模 | 原话、建议值、待澄清项及本次确认内容 |
| 蓝图确认 | 查看并调整目标、题位、题型、分值 | 普通任务供给、目标支持证据状态、缺题原因和可执行调整 |
| 试卷编辑 | 换题、锁定、评分、预览和确认成卷 | 已选题数、有效分值、未完整卷、保存与输出状态 |
| 组卷历史 | 恢复草稿，查看成卷，派生新草稿 | 草稿与不可变成卷的区别、保存时间和实际题数 |

“有候选题”和“候选已证实支持教学目标”分别说明。必须目标未获支持时，明确指出阻断目标及缺少的证据；调整要求由教师决定，不自动降级。

修改题位任务保留兼容目标，清除该题位的过期规划理由。教学目标面板默认收起；必须目标失去兼容关联时自动展开，显示待关联数量并暂时禁用开始选题。通过“关联题位”在固定高度弹窗中选择兼容题位，确认后才修改规划；没有兼容题位时引导调整任务或需求，不自动放宽条件。关联变更同步清除受影响题位的旧理由，但不代表已取得目标覆盖证据。

试卷名称在编辑阶段点击页头修改，Enter 或失焦保存、Escape 取消；成卷确认内允许最后修改，保存名称后按最新修订确认。失败保留输入并允许重试，版本冲突需读取最新草稿；已确认成卷不提供直接改名。历史列表在标题下显示紧凑学生标签，多个姓名显示首位与额外人数，完整名单保留在悬浮说明和可访问描述中，不额外增加列表行数。

桌面编辑页去掉常驻步骤导航，题型 Tab、总题量与全选同行，确认成卷、预览和添加题目位于题目右侧并随滚动保持可用。“组卷说明”使用右侧抽屉，展示需求及当前题位的题号、题型与考查点，点击外部或按 Escape 关闭；只读查看不改变当前成果。添加题位默认跟随当前题型，切换题型同步更新考查点选项。带 Tab、搜索或其它切换功能的模态框固定外框高度，内容内部滚动。滚动区预留固定滚动条空间，切换题型不改变题目宽度；窄屏操作移至题目上方，批量操作不能挤动题目。

桌面历史项使用标题和一行归属／题量／日期信息，切换记录时不让整列变淡，不重排列表。每项右侧提供删除图标，鼠标悬浮、键盘聚焦或触控时可用；确认后从列表移除，保留题库和已有 PDF。题库筛选依次展示搜索、题型、难度、能力与核心素养，不折叠低频选项，窄屏换行；组卷篮的标题与生成操作位于题目上方，浏览长题目列表时保持可用。

组卷说明逐题显示难度，区分题位目标与已选题的内容估计；没有版本一致的冻结标注时显示未评估，不以教师要求或规划理由代替实际评估。单选、多选、填空、解答使用统一题型入口；旧需求的多选数量默认为零。多选无供给时明确说明具体缺口，不改为单选或减少总题量。

难度要求提供基础、基础偏中等、中等、中等偏较难、较难五档，在已有“调整题目”弹窗中显式确认保存，不将旧数值自动转换为分档，也不改写现题内容估计。每题操作区增加“详情”，点击右侧抽屉查看题目难度、考查点、知识点和来源；题位要求单独展示，解法依赖默认收起。主页面不铺开这些字段、不为入口预留额外空白；抽屉只读，支持外部点击与 Escape 关闭。

考查范围沿用本地真实教材 → 章 → 小节树，按真实目录排序，支持父级全选／半选和保留祖先层级的搜索；无组卷任务的小节展示但禁选，已选身份保留。固定搜索栏和弹窗外框，列表独立滚动，避免双滚动条。

五档内容判断见 [难度口径](difficulty-rubric.md)，难度选择处显示当前档说明，可展开全部对照；界面与 Rust 规划提示共用一份标准。知识点数量、计算量或题型不单独决定等级，两个过渡档分别强调一次简单处理和一个实质性解题关口。不把内容估计视为学生正确率，不自动重标旧题。

模型执行区域显示当前步骤、调用状态、耗时、失败原因及可核验的简短结果说明；不展示或编造隐藏思维链。运行时提供停止操作，失败保留教师输入和已确认成果。原始错误仅展示经去除密钥、凭据及敏感请求信息后的必要诊断，不直接渲染任意供应商响应。

2026-10-21 用户进一步要求：发送组卷输入后进入独立过渡页，按实际后端事件说明识别范围、核对供给、整理要求的进展。每步至少展示约 650ms，再进入需求确认，避免快速步骤闪过；该等待只用于界面呈现，不阻塞后端，不把已完成的模型请求冒充仍在执行。显示耗时保留实际处理完成时间，停止须清理展示计时器并阻止晚到跳转，已整理结果保留供显式查看；减少动态效果时取消位移动画，仍保留可读步骤。

2026-10-22 后续精简：独立过渡页不再重复展示教师输入气泡和“组卷助手”标题，运行中仅在步骤列表中展示当前步骤；保留耗时、停止和必要的失败／重试反馈。原始输入状态及展示延迟保持不变。编辑草稿的缺题卡直接显示已确认的具体考查点，优先使用题位保存的任务名称，兼容冻结目录中的任务名称；没有记录时如实说明，不用宽泛章节名或新模型建议补造考查点。

2026-10-22 题位安排沿用独立过渡页：教师确认需求后，按后端实际阶段显示“核对题库供给 → 安排考查点与题位 → 校验题位规划”，规则与 AI 路径均显示，不重复铺开需求表单或加载条。每阶段沿用约 650ms 的最短可读时间，不延迟后端；完成后只进入题位规划确认，不自动选题。停止或失败保留已确认需求，可返回确认或显式重试；展示延迟期间停止不触发晚到跳转，已完成规划保留供显式查看。

2026-10-22 开发者诊断：普通界面隐藏入口，正式 EXE 可通过 `--developer` 或启动环境 `TUTOR_DEVELOPER_MODE=1` 显式开启；Rust 校验开发者权限，前端不能仅凭开发构建变量开放读取。组卷页面右下角提供“开发日志”悬浮窗口，非模态、不遮罩或锁定工作区，支持收起、放大与独立滚动，处理中仍可查看；关闭、收起、暂停刷新或页面进入后台时停止轮询。按同一次组卷关联需求、规划、选题、编辑、预览、成卷和 PDF 事件，重试保留关联；日志只读，不改变当前组卷、不触发模型调用。

用户明确要求开发者日志包含每一步实际正文：逐事件按需查看输入、输出、实际模型请求（含提示词）、原始响应、解析结果及校验信息，允许复制。普通元数据列表不承载整段正文；开发正文仅显式开启期间采集，密钥、认证头及学生关联信息在写入前移除。历史未采集、保留淘汰与大小截断如实标明，不将缺失记录补写为实际执行数据。

同日后续要求取消教学规则路径：新建、需求确认和蓝图确认不再显示规则方式选择或失败兜底。未配置模型先引导设置，保留输入；失败可重试或修改要求。换题由模型依据真实题面评估，仅展示通过当前适配判断的可选题，空结果明确显示缺口，不铺满禁用的无关题。导入和答卷结果不再被关键词或置信档阈值二次判定，必要的数据与证据校验继续适用，详见 ADR-0009。

前置库存读取仅说明真实就绪题目的数量，不标成已经核实的教学适配供给。过程名称与说明应区分库存读取、模型判断及结构校验。

教师整卷预览及教师 PDF 逐题显示难度依据，使用与题目内容和教师资料版本一致的冻结难度标注，复用安全富文本渲染。依据缺失或版本失效保持未记录，不拿目标难度、规划理由或解法正文替代，也不读取当前题库回填旧成卷。教师 PDF 的长题及依据允许连续跨页，题头与小标题衔接后文，单张图片和表格行保持完整，避免整题避分页造成仅有卷头的空白首页。学生预览及学生 PDF 不显示这些教师资料；已生成的旧 PDF 保留，由用户显式更新排版。

## 使用指南

2026-10-23 题库详情去重：主考知识优先显示正式关联，兼容旧 AI 知识说明时明确其来源；考查点／考点合并为“考查任务”，优先采用同版本教学稿，缺失时显示原有任务标注。保留难度依据与学生作答要求的不同职责，空的任务、作答要求、能力和素养不占位。教材位置、非空能力素养、来源与模型来源统一放入默认收起的“更多信息”；待复核提示保持可见。数据库教学稿同步采用 ADR-0006 的 v2 合同，既有冻结成果保持原快照。

2026-10-20：侧栏底部提供“使用指南”；新建组卷的“了解如何组卷”和导入页的“导入说明”直接打开对应主题。
指南使用稳定外框的只读弹窗，不切换当前工作区，不覆盖教师输入、草稿或导入审核内容。
两份说明分别解释组卷确认流程和原卷导入流程，每一步说明系统处理、教师确认及可见结果。
采用本地组件演示，明确标为“演示示例”；默认静态，用户可逐步查看或播放、暂停和重播，播放结束后停止。
减少动态效果时保留静态说明及逐步操作，不自动播放。切换主题或离开可见页面停止播放，关闭释放计时器。
查看指南不调用模型／OCR，不读写业务数据；指南须说明实际文件导入会发送至用户配置的识别及模型服务，不能声称导入全程离线。
