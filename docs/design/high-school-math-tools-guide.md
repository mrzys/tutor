## 一、 代数与不等式最值板块

### 工具 1：常数代换法（“乘 1 法”）
- **识别特征**：已知条件为**倒数和等于常数**（如 $\frac{a}{x} + \frac{b}{y} = 1$），所求式子为**一次整式和**（如 $mx + ny$）求最小值。
- **思维动机**：所求两项相乘无法直接消去变量，利用常数“1”将已知条件乘入所求式，展开后即可构造出积为常数的互倒项。
- **课堂板书规范**：
  > “观察已知条件为倒数和，利用常数代换（乘 1 法），将所求式子乘以 1 展开：\
  > $mx + ny = (mx + ny)\left(\frac{a}{x} + \frac{b}{y}\right) = (am + bn) + \left(\frac{bmx}{y} + \frac{any}{x}\right)$。\
  > 由基本不等式可得最小值，当且仅当两项相等且代入条件有正解时等号成立。”
- **避坑与反暴力**：严禁把已知等式看作关于某一变量的一元二次方程使用求根公式消元。

### 工具 2：消元降维法（主元法）
- **识别特征**：二元或多元问题，条件中能较容易地用一个变量直接表示出另一个变量（线性关系或显式函数），或者含有多个字母求参数范围。
- **思维动机**：高中的基本认知习惯是“能研究一元就不研究二元”。明确以哪一个字母为主元，将多元问题降维为一元函数求最值。
- **课堂板书规范**：
  > “由已知等式解得 $y = f(x)$，代入所求式化为关于 $x$ 的单变量函数 $g(x)$。注意 $y$ 的取值范围对 $x$ 产生的自变量范围制约。”

### 工具 3：分离常数法与对勾函数模型
- **识别特征**：分式结构分子分母同阶（如 $f(x) = \frac{ax+b}{cx+d}$），或者变形后出现 $t + \frac{k}{t}$（$k>0$）的结构。
- **思维动机**：直接求导容易繁琐；通过分子配凑分母分离出常数，或换元后化为标准的对勾函数 $g(t) = t + \frac{k}{t}$，利用单调性直接写出区间最值。
- **课堂板书规范**：
  > “将分子拆分为含分母的整式，分离常数得 $f(x) = A + \frac{B}{cx+d}$；若换元令 $t = g(x)$，则化为对勾函数模型 $t + \frac{k}{t}$，结合 $t$ 的定义域与对勾函数单调区间得出最值。”

### 工具 4：换元与对称化（和积代换）
- **识别特征**：代数式中 $x, y$ 地位完全对称，大量出现 $x+y$ 与 $xy$。
- **思维动机**：令 $u = x+y, v = xy$，利用判别式 $\Delta = u^2 - 4v \ge 0$ 保障实数解存在，将二元最值转化为单变量参数取值。

## 二、 数列通项与求和板块

### 工具 5：待定系数法构造等比数列
- **识别特征**：递推关系为一阶线性型：$a_{n+1} = p a_n + q$（$p \ne 1, q \ne 0$）。
- **思维动机**：不能直接求和，两边同时加上待定系数 $\lambda$，凑成 $a_{n+1} + \lambda = p(a_n + \lambda)$，从而将非等比数列转化为以 $\{a_n + \lambda\}$ 为主体的公比为 $p$ 的等比数列。
- **课堂板书规范**：
  > “设 $a_{n+1} + \lambda = p(a_n + \lambda)$，展开对比得 $\lambda = \frac{q}{p-1}$。故 $\{a_n + \lambda\}$ 是以 $a_1 + \lambda$ 为首项、$p$ 为公比的等比数列。”

### 工具 6：累加法与累乘法
- **识别特征**：递推式为差分型 $a_{n+1} - a_n = f(n)$ 或商值型 $\frac{a_{n+1}}{a_n} = f(n)$。
- **思维动机**：通过写出连续项依次累加或累乘，中间项两两抵消，直接求得 $a_n$ 通项。
- **课堂板书规范**：
  > “当 $n \ge 2$ 时，$a_n = a_1 + (a_2 - a_1) + \cdots + (a_n - a_{n-1})$，再代入 $n=1$ 验证首项是否吻合。”

### 工具 7：裂项相消法
- **识别特征**：数列通项分母为相邻因式的乘积，如 $\frac{1}{n(n+k)}$、$\frac{1}{(2n-1)(2n+1)}$ 或 $\frac{1}{\sqrt{n} + \sqrt{n+1}}$。
- **思维动机**：将通项拆成前后两项的差：$a_n = \frac{1}{k}\left(\frac{1}{n} - \frac{1}{n+k}\right)$，求和展开时首尾相消，化繁为简。
- **课堂板书规范**：
  > “将通项裂项为 $a_n = \frac{1}{k}\left(\frac{1}{n} - \frac{1}{n+k}\right)$，求和式展开后前后两两对消，仅剩余首尾有限项。”

### 工具 8：错位相减法
- **识别特征**：通项为“等差数列 $\times$ 等比数列”的乘积形式，如 $T_n = \sum (an+b) q^n$。
- **思维动机**：将和式 $S_n$ 两边同乘公比 $q$，两式错开一位对应相减，将复杂的差比数列求和降维为纯等比数列求和。
- **课堂板书规范**：
  > “写出 $S_n$ 展开式，两边同乘公比 $q$ 得到 $q S_n$；两式错位相减得 $(1-q)S_n = \cdots$，利用等比数列前 $n$ 项和公式求出最终表达式。”

## 三、 函数与导数综合板块

### 工具 9：指对同构法（结构对称转化）
- **识别特征**：不等式或方程中同时混杂 $e^x$ 与 $\ln x$，或者结构呈现 $A e^A$ 与 $B + \ln B$ 的特征。
- **思维动机**：两边暴力求导极为复杂；通过移项变形，凑出两边完全相同的函数结构 $f(t)$（例如 $f(t) = t e^t$ 或 $f(t) = t + \ln t$），将问题转化为函数单调性的比较。
- **课堂板书规范**：
  > “原式可等价变形为 $f(A) > f(B)$。构造函数 $f(t) = t e^t$，因为 $f'(t) > 0$，所以 $f(t)$ 在区间上单调递增，故不等式等价于 $A > B$。”

### 工具 10：隐零点设而不求
- **识别特征**：导函数 $f'(x) = 0$ 是超越方程，无法直接解出具体的根 $x_0$，但能确定其存在且唯一。
- **思维动机**：设出根为 $x_0$，建立等式关系（如 $e^{x_0} = \frac{1}{x_0}$）；将 $x_0$ 作为中介代入极值式化简，最后再消去或估计范围。
- **课堂板书规范**：
  > “设 $f'(x)$ 在区间内存在唯一零点 $x_0$，满足 $f'(x_0) = 0$ 即关系式 $g(x_0)=0$。将极值 $f(x_0)$ 代入该关系式消元化简，转化为关于 $x_0$ 的单变量函数。”

### 工具 11：极值点偏移（差函数法 / 对数均值模型）
- **识别特征**：已知 $f(x_1) = f(x_2) = c$（$x_1 \ne x_2$），且函数存在唯一极值点 $x_0$，要求证明 $x_1 + x_2 > 2x_0$ 或 $x_1 x_2 > x_0^2$。
- **思维动机**：因为极值点左右不对称发生偏移，通过构造对称差函数 $F(x) = f(x) - f(2x_0 - x)$，利用其单调性证明。
- **课堂板书规范**：
  > “不妨设 $x_1 < x_0 < x_2$。构造对称差函数 $F(x) = f(x) - f(2x_0 - x)$，对 $F(x)$ 求导判断单调性，得出 $f(x_1) > f(2x_0 - x_1)$，进而由单调性完成证明。”

### 工具 12：端点效应（必要性探路）
- **识别特征**：带参不等式恒成立问题，直接分类求导极其繁琐。
- **思维动机**：先看区间端点（如 $x=0$ 或 $x=1$）处不等式成立的“必要条件”，迅速将参数范围锁定在一个很小的闭区间内，然后再反过来证明充分性。
- **课堂板书规范**：
  > “（必要性探路）因为不等式在定义域上恒成立，取特殊端点 $x=0$ 代入，得参数必满足 $a \le 1$；（充分性证明）当 $a \le 1$ 时，求导证明不等式恒成立。”

## 四、 平面解析几何板块

### 工具 13：设而不求联立法（点差与韦达定理）
- **识别特征**：直线与圆锥曲线相交，求弦长、三角形面积、线段比例或定点定值。
- **思维动机**：绝不解出交点坐标的具体根。设出直线方程与交点 $A(x_1, y_1), B(x_2, y_2)$，联立二次曲线消元，全程用根与系数的关系（韦达定理）表达几何量。
- **课堂板书规范**：
  > “设直线方程为 $y = kx + m$（或 $x = my + n$），与曲线方程联立整理得关于 $x$ 的一元二次方程。由 $\Delta > 0$ 及韦达定理写出 $x_1+x_2$ 和 $x_1 x_2$，代入弦长/面积公式化简。”

### 工具 14：中点弦点差法
- **识别特征**：已知弦的中点坐标，求弦所在直线的斜率或轨迹方程。
- **思维动机**：常规联立计算量极大；将两端点代入圆锥曲线方程两式作差，直接得出斜率 $k$ 与中点坐标 $(x_0, y_0)$ 的积商关系，**一步求出斜率**。
- **课堂板书规范**：
  > “设弦两端点为 $A(x_1, y_1), B(x_2, y_2)$。两点均在椭圆上，代入方程并作差：\
  > $\frac{x_1^2 - x_2^2}{a^2} + \frac{y_1^2 - y_2^2}{b^2} = 0 \implies \frac{(x_1+x_2)(x_1-x_2)}{a^2} + \frac{(y_1+y_2)(y_1-y_2)}{b^2} = 0$。\
  > 代入中点坐标与斜率定义，直接解得直线斜率 $k = -\frac{b^2 x_0}{a^2 y_0}$。最后检验 $\Delta > 0$ 确保直线与曲线有交点。”

### 工具 15：齐次化联立法
- **识别特征**：圆锥曲线上存在两点 $A, B$，已知直线 $OA, OB$ 的斜率之和或积为定值，求直线 $AB$ 过定点。
- **思维动机**：避免硬算 $k_{OA} + k_{OB}$ 的复杂韦达代换。将直线方程写成截距形式，代入二次曲线方程构造二次齐次式，直接将交点斜率转化为方程的根。
- **课堂板书规范**：
  > “设直线 $AB$ 方程为 $mx + ny = 1$。将直线代入曲线方程进行齐次化处理，两边同除以 $x^2$ 得到关于斜率 $k$ 的一元二次方程，直接应用韦达定理得出结论。”

### 工具 16：圆锥曲线定义法转化
- **识别特征**：涉及焦点坐标、准线距离、焦点弦、焦点三角形周长或面积。
- **思维动机**：凡带焦点的题目，优先回归定义（如椭圆 $|PF_1| + |PF_2| = 2a$、抛物线到焦点距离等于到准线距离），用几何定义代替两点间距离公式硬算。

## 五、 三角函数与解三角形板块

### 工具 17：正余弦定理边角互化
- **识别特征**：题目给出混杂着边与角的等式（如 $a\cos C + c\cos A = 2b$）。
- **思维动机**：统一方向——要么“全部化角”（用正弦定理），利用诱导公式和三角恒等变换求角；要么“全部化边”（用余弦定理），利用代数因式分解求边的比例。
- **课堂板书规范**：
  > “（角化边）：利用正弦定理，将等式中的 $\sin A, \sin B$ 转化为 $a, b$ 代数式；或（边化角）：利用余弦定理将边用角表示，利用三角恒等式化简。”

### 工具 18：辅助角公式（降幂与相位合成）
- **识别特征**：函数解析式中出现平方项 $\sin^2 x$、乘积项 $\sin x \cos x$ 或线性叠加 $a\sin \omega x + b\cos \omega x$。
- **思维动机**：先用二倍角公式降幂，再用辅助角公式 $A\sin(\omega x + \varphi) = \sqrt{a^2+b^2}\sin(\omega x + \theta)$ 合成单一正弦型函数，进而讨论周期性、最值与对称性。

### 工具 19：平面几何直观辅助法（角平分线 / 面积桥梁）
- **识别特征**：解三角形中涉及角平分线、中线、高线或外接圆半径 $R$。
- **思维动机**：利用 $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle ACD}$（角平分线面积法）或中线向量公式 $\vec{AM} = \frac{1}{2}(\vec{AB} + \vec{AC})$ 建立等式，避免陷入余弦定理繁琐方程。

## 六、 平面向量与立体几何板块

### 工具 20：平面向量基底分解与极化恒等式
- **识别特征**：几何图形中求数量积 $\vec{AB} \cdot \vec{AC}$，或已知中点求向量数量积范围。
- **思维动机**：
  - 基底法：选取两条有明确夹角和长度的向量为主基底，将所有未知向量线性表示；
  - 极化恒等式：$M$ 为 $BC$ 中点，则 $\vec{AB} \cdot \vec{AC} = |\vec{AM}|^2 - |\vec{BM}|^2$，直接将数量积转化为长度模长的计算。

### 工具 21：空间向量坐标建系法
- **识别特征**：立体几何大题求二面角、线面角、点到平面的距离。
- **思维动机**：找出三条互相垂直的线段建立空间直角坐标系，写出各点坐标，求出平面的法向量 $\vec{n}$，将几何证明转为向量内积纯代数计算。
- **课堂板书规范**：
  > “以 $O$ 为坐标原点，建立空间直角坐标系 $O-xyz$。写出关键点坐标及向量，设平面法向量为 $\vec{n}=(x,y,z)$，由 $\vec{n} \cdot \vec{u} = 0$ 解得法向量，再由公式 $\cos\theta = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$ 求二面角。”

### 工具 22：等体积法与几何投影转化
- **识别特征**：三棱锥中求底面不规则的点到平面距离，或空间垂直关系直观明显。
- **思维动机**：建系繁琐时，利用三棱锥换底公式 $V_{A-BCD} = V_{D-ABC}$，通过面积与已知高快速求出点面距。

## 七、 概率统计与计数原理板块

### 工具 23：古典概型“正难则反”（对立事件法）
- **识别特征**：题干出现“至少有一个”、“至多有两个”、“不全相等”等词眼。
- **思维动机**：正面分类讨论情况过多时，立刻转向求对立事件的概率 $P(A) = 1 - P(\bar{A})$。

### 工具 24：经典分布列模型精准匹配
- **识别特征**：有放回抽取（二项分布 $X \sim B(n, p)$）vs 不放回抽取（超几何分布 $X \sim H(N, M, n)$）。
- **思维动机**：审清抽取方式，直接套用标准概率模型公式计算分布列、期望与方差，杜绝机械列表列举。

## 八、 集合逻辑与复数板块

### 工具 25：复数几何意义与模长三角不等式
- **识别特征**：复数满足 $|z - z_0| = r$ 或求 $|z - z_1| + |z - z_2|$ 最值。
- **思维动机**：将复数 $z$ 看作复平面上的动点 $P(x,y)$，利用圆或椭圆的几何距离性质求解，避免设 $z = x+yi$ 展开陷入复杂代数运算。

### 工具 26：数轴法与 Venn 图法
- **识别特征**：集合包含参数的交、并、补集运算，或充要条件参数范围。
- **思维动机**：画数轴标出端点，特别注意“空集 $\varnothing$ 的讨论”与“端点值是否能取到（闭/开区间）”。

## 九、 教学解析语言与板书禁忌对照表

| 序号 | 严禁使用的大学/学术黑话 | 推荐替换的高中规范板书语言 | 适用场景 |
| :---: | :--- | :--- | :--- |
| 1 | **约束条件**（Constraint） | **由已知条件 / 由题意** | 审题与前置条件引入 |
| 2 | **目标式 / 目标函数**（Objective） | **所求式子 / 要求的最值** | 目标变形与化简 |
| 3 | **上界 / 下界**（Upper/Lower bound）| **最大值 / 最小值 / 范围** | 不等式推导收尾 |
| 4 | **线性组合**（Linear combination）| **配凑变形 / 适当系数相加** | 基本不等式与代数配凑 |
| 5 | **单位量 / 构造单位算子** | **两边同除以某项化简** | 齐次式变形 |
| 6 | **显然 / 易得**（Trivial） | **写出核心推导依据（如“由正弦定理”）** | 关键定理衔接处 |
| 7 | **存在性与紧致性** | **检验等号能否取到 / 满足定义域** | 最值取等检验 |
