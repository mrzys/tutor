## 单题按需参考

下列条目列出题面关系、可尝试的方法和必要条件，不是强制顺序，不按题型关键词机械套用。

### 1. 代数与不等式

```text
已知和或倒数和为常数时，先看代入、配方、乘以等于1的式子或分离常数能否连起已知与所求，再考虑基本不等式。解释配凑的来由；使用不等式核对正负，求最值同时核对等号能否满足原条件。
若倒数和等于1，所求式子又能用这些分母表示，可先将所求式子乘以这个等于1的式子并展开，观察是否出现乘积为常数的两项。若所求是两个量的和或差，可先展开它的平方，与已知等式对照，看看能否直接配成完全平方。上述变形若已能完成证明与取等检验，就省去另求变量根式、重复消元或增加换元；不适用时仍选其他完整的高中解法。
```

### 2. 数列

```text
相邻项的差、比或一次递推关系可考虑累加、累乘或平移后构造等差等比；求和观察能否裂成相邻项之差，或是等差与等比项乘积，再考虑错位相减。核对首项、下标及项数，通项不能仅凭前几项猜测。
```

### 3. 函数与导数

```text
先看定义域、单调性与对称性能否直接联系条件；配方、函数性质和导数按已学范围选用。利用单调性由函数值相等推出自变量相等时，须在包含二者的区间严格单调。交代导数符号、区间与关键构造的来由，不直接援引未说明的增长比较或极限。
```

### 4. 解析几何

```text
先看曲线定义及几何性质；只需求交点坐标的和或积时可联立后用根与系数关系，涉及弦中点时可把两点方程相减。核对交点存在、重根、除数非零及斜率不存在的情况；需要具体坐标时正常求解。
```

### 5. 三角

```text
边角混合时考虑正余弦定理统一表示；同角正余弦的一次式可用辅助角，几何关系直接时可用几何法。核对角的范围、符号和多解，不因变形丢失原角度条件。
```

### 6. 向量与立体几何

```text
按已知方向分解向量或使用数量积；空间关系先看几何定义和判定定理，再考虑合适坐标系。核对平行、相交、异面与图形位置，空间两直线垂直不一定相交；反例须满足全部已知条件。
```

### 7. 概率统计与计数

```text
先明确事件与计数对象，再看分类分步、对立事件或适用分布。正态概率可先看均值两侧对称关系，不必机械标准化。核对是否等可能、互斥、独立及重复试验条件；概率相等转成自变量关系须说明理由。
```

### 8. 集合、逻辑与复数

```text
先把定义、量词和充分必要条件写成具体包含或代数关系；新定义集合先按定义检验。一般结论给一般证明，整数系数可比较系数、因式分解或讨论除法余数；复数可按题意选代数运算或几何表示。不为简单关系另起陌生命名。
```
