## 证据边界

- 每项绑定当前 `catalogVersion` 与旧 definition 原 UTF-8 字符串的 SHA-256，防止定义变化后静默沿用旧核对。
- `evidence.quote` 是已存逐页文本的真实连续子串；`textSha256` 按文件原字节计算。没有纠正 OCR 后伪装成源摘录。
- 三册印刷页到 PDF 物理页均加 5。旧页与首次定义、解释或实际应用页不同的情况，记录于 `legacyPageDiscrepancy`，没有覆盖旧页码。
- 第一、二册 OCR 和第三册 PDF 字体映射均可能损坏数学表达。已对关键疑点实际渲染源页，记录 `visualEvidence` 的源 PDF 哈希、物理页、渲染图哈希。由视觉解除歧义仍保留原始文字和待教师复核状态。
- `text_evidence_matched` 表示旧定义主体可找到语义对应，并可用视觉证据解释识别问题；不是清洁公式数据，更不是可自动用于命题的授权。
