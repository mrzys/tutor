# 组卷优化与正式试卷 PDF 验收（2026-10-12）

## 已落实

- AI 蓝图上下文包含候选的实际题面与解析片段，选题后按教师确认目标复核实际题面。检查项必须来自确认目标原文，依据必须引用当前题目；题目或需求修改后旧复核失效。
- 换题前核查实际供给；同任务与同知识范围其他任务的候选分别呈现。跨任务替换须明确目标任务，保留题位与教学目标。无候选时返回澄清，不生成无法执行的换题行动。
- 50 道旧题通过当前 DeepSeek 补充难度分档。358 道可用题现为基础 148、常规 161、提高 49、未知 0；均为模型内容估计，未冒充学生作答标定。题面、答案、解析及其版本未改。
- A4 学生卷采用正式标题、班级姓名考号栏、中文题型分区、连续题号、按宽度排列的选项和解答题留白。教师卷增加答案速查与逐题解析；技术身份信息保留后台。
- 计分与不计分分别输出；旧 PDF 可下载，主动重新生成更新排版。PDF.js 画布预览直接读取与下载相同的 PDF，支持学生／教师切换及翻页，所有字体与解码资源本地加载。
