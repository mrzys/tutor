# 桌面迁移验证（2026-10-17）

本记录为工程模拟／回归验证，不代表真实教师使用或教学效果。

## 已验证

- SolidJS 类型检查及 Vite 生产构建通过；Rust Windows 应用编译通过。
- Rust 33 个测试通过，覆盖空白个人库、学生关联、真实版本化种子、严格题量、缺题保留、题位匹配、取消、修订冲突、幂等重试、不可变成卷、快照篡改拒绝、PDF 哈希及路径边界。
- 模拟模型 HTTP 返回不能覆盖教师明确的 12 题、无解答题、30 分钟、不计分要求；关联学生未发送给模型。
- 浏览器通过实际 Rust stdio IPC 完成 45 次调用；测试保存成功但响应丢失后的改名、成卷重试，未产生重复成卷。
- 原生 Windows WebView2 实际执行首次昵称设置、本地选题、成卷和 PDF 导出。学生卷 2 页、教师卷 4 页均生成并逐页检查。
- 原生应用内，打包的 PDF worker 连续展示学生 2 页和教师 4 页；读取检查 SHA256，切换版本、旧异步响应和尺寸变化不会覆盖当前结果，销毁后释放画布。
- 390px 布局检查、输入框光标附近学生匹配和 Tab／Enter 选择、勾选题目高度稳定通过；无页面错误。
- 只读目标文件导致导出失败时，原 PDF 字节保持不变。
- 损坏 JSON、Base64 或 DPAPI 模型设置不会阻止本地工作区启动；原文件保留，显式重设时先备份，再保存配置。

## 数据与迁移范围

用户选择桌面个人数据从空白开始；所有回归使用仓库外临时目录。
旧网页运行进程、数据库及用户记录未迁移、清理或重建。桌面安装包使用独立个人 SQLite 和题库 SQLite，不依赖 Node 服务。

题库当前导入仓库 45 道已核验版本化种子；旧运行库额外题目未宣称完成迁移。
组卷主流程已移植；旧上传审核、AI 单题调整、整卷目标覆盖检查尚未移植。
外部图片等附件题目暂不能冻结成卷，会明确报错并保留草稿；不会生成缺失附件的正式试卷。
跨平台打包尚未验证，首个交付平台为 Windows。

Windows x64 正式构建和 NSIS 安装包生成成功（智教 0.1.0）。安装包使用项目独立打包工具缓存，不修改异常的旧共享缓存。
