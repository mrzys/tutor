# S3-05 需求侧工程交付记录

日期：2026-10-10。范围：[任务规格](../tasks/s3-05-teaching-requirements.md)的需求确认、目标关联、未知支持边界和独立分析接收；真实题目目标支持尚待接入。

## 实际行为

- 需求页新增可选的具体教学目标：教师原话、稳定身份及版本、知识范围、认知要求、可观察表现、提示／作答条件、必须／尽量、可选能力与素养。认知分类为项目内部用语，目标难度可不指定。
- 按目标章节与作答形式从现有任务预设建议题位。教师可直接调整目标关联；显示待澄清、范围／形式冲突和未安排目标。需求摘要与蓝图一次确认，随后真实选题并保存。
- 原任务索引不算新目标支持。关联的必须目标当前支持未知，题位留空；偏好目标允许其他条件符合的题目选入，但保留支持未知，不计为已证实覆盖。模糊短语“活题”等提供解释概念、常规应用、独立选方法三种澄清方向；没有自动理解任意自然语言的能力。
- 草稿保留目标、关联、差异和版本；基线更正需递增已改变目标的版本，保留题目与锁定、归档历史。冻结成卷保存完整定义，不因后续变化改写。
- `analysis:receive` 独立保存原分析与信封，强制待复核，不自动更改题包、台账或选题结论。当前没有将这些原始分析变成合格候选的适配器。
