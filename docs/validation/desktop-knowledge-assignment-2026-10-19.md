# 桌面题目知识点直接关联

依据用户 2026-10-19 的明确决定，题目匹配目录中已有知识点 UID 后直接关联，不再设置单独的待确认门槛。

## 实现边界

- 历史 `pending_uid_mapping` 仅作为原迁移档案状态保留，已有 UID 的关联直接用于桌面知识点题数和筛选；不重写原快照、不修改原网页数据库。
- 新导入模型选择保存 `model_mapped`，教师改选保存 `teacher_assigned`，来源依据不借用题目内容审核记录。
- 知识点关联不再依赖 `mappingConfirmed`。题目入库前的原文、答案、解析、公式和图表完整性审核仍保留；自动选题所需主考范围及完整解法依赖确认保持独立。
- 未知 UID 拒绝；不根据知识图谱的前置或相关边自动添加题目标签，不自动调用模型重新标注旧题。

以下为隔离数据目录中的开发回归，不是真实教师使用案例。

- `npm run build`：SolidJS TypeScript、Vite 和 Rust 检查通过。
