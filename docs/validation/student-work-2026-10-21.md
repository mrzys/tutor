# 学生答卷与后台批改：隔离验收

日期：2026-10-21。当前状态：已完成隔离真实 Rust／本机模拟服务回归及浏览器目标验收。核心 14 组、最终扩展 6 组、浏览器定向 13 组通过；这不是逐项完整覆盖声明，也不代表真实批改质量已获验证。

## 范围与依据

以 [ADR-0007](../adr/0007-student-answer-grading.md) 和本轮用户授权为准：学生基本资料 → 选择本机成卷或提供外部完整原题和练习名称 → 保存答卷原件 → 后台 LLM 批改 → 查看历史与按需教师修正。
同日研究稿的“首版暂缓模型批改”建议已被取代。本次不建设班级、学生账号、掌握度分析、教学计划或自动修改组卷条件。

验收区分三个层面：原件和身份是否可靠保存；后台流程及结果校验是否正确；真实手写识别与数学判断是否准确。
本轮本机模拟服务仅验证前两层，不据此声称实际数学评分准确、教师愿意采用或教学有效。

## 隔离方法

- 使用仓库外临时目录、模拟昵称和学生；真实 Rust stdio driver 处理 IPC、SQLite、文件、后台任务和模型请求，不以 localStorage 或前端业务假响应替代持久化。
- 启动前写入空模型配置，禁止开发环境根 `.env` 自动提供真实服务；模型与 OCR 均仅配置 `127.0.0.1` 模拟服务，使用无效模拟密钥。
- 前端浏览器通过实际 Rust driver 桥接，验证目标操作、2048／1440／390 宽度及控制台；截图、脚本、调用日志均保存在仓库外临时目录。
- 本会话未提供 Browser 插件及其 browser skill，按前端测试技能使用 Playwright 回退；不以页面 mock 或 localStorage 代替业务持久化。页面身份、非空、无开发错误浮层、控制台、截图及目标交互均纳入上述浏览器检查。
- 仅模拟上传材料；记录请求次数、请求上下文和结果。检查模型请求不额外携带学生姓名、年级、昵称和自由备注；图像本身可能含身份信息，不作自动去标识承诺。
- 测试前后核对隔离题库及冻结成卷哈希，重开 driver 验证持久化；不得触碰真实用户库、旧网页个人记录或外部服务。

## 契约核对点

当前约定 IPC：`students_get`、`students_update`、`student_work_create/list/get/file_read`、`student_work_start/retry/cancel`、`student_work_override`。
创建保存与发起外呼必须分开；前端不能在查看历史时自动重试。
后台状态为 `saved/queued/running/completed/failed/cancelled/interrupted`，结果状态为 `correct/incorrect/partial/unanswered/unable`，二者不可混用。
`attempts` 表示批改尝试历史，不能展示为学生实际作答次数。教师修正必须单独标明，模型置信度不表示正确率或教师审核状态。

当前实施没有完整的补传原件、订正／重做关系、原件页序旋转、批注及备份导出工作流。这些属于后续范围，不能把批改重试历史冒充补传或学生重新作答历史。

截图已实际查看，原件可读、移动模态内容可滚动、主要保存按钮可见。测试没有访问真实用户数据库，没有外部 OCR／LLM 消费。真实 Rust 完成原件落盘、逐文件识别、后台模型请求、结果归一化、教师修正及重开恢复，模型只由本机 HTTP 服务模拟。

定向乱序用例只延迟真实 Rust 已读取的旧 revision `student_work_get` 响应：界面保存教师修正后再释放旧响应，判断和备注均未回退。再次批改返回未知题位导致失败后，真实存储保留原模型与教师修正；界面显示具体错误，并明确“以下为上次完成的批改结果，本次批改已失败”。

最终外部原题对照回归同时验证：上传完整原题并单独上传答卷，以及明确答卷包含完整题干，两种真实文件链路均完成逐文件OCR与LLM请求；模型返回的题干逐字存在于相应OCR源材料时可判定正确。将模型题干改成上传材料中不存在的另一题，即使模型自报高置信，Rust也归一为 `unable`。外部题不宣称全卷完整，也不将模型推导保存成原卷答案。

初次脚本曾使用无效模拟PNG，Rust如实报`ocr_invalid_image`，改为浏览器生成有效PNG后通过。另一次UI执行时源码热更新使模态重挂载，最终稳定版重跑通过；这些失败保留在临时目录，不作为最终通过证据。

真实手写、缺页／错页、复杂数学过程、跨页解答和评分方案仍需要真实材料独立核验；模拟服务不能证明这些质量。正式试用前需要保留可核对的原件和逐题判断证据。
本轮浏览器使用 IPC 桥接真实 Rust；原生 Tauri 窗口、WebView2 打印及双向运行锁的原生窗口压力测试不包含在浏览器证据中。
