# MVP：点击式需求与生成式 UI

日期：2026-10-10。依据 [ADR-0004](../adr/0004-mvp-application-stack.md) 和 [UI 应用说明](../design/tutor-ui.md)。本记录描述工程交付，不代替教师实际采用反馈。

## 已实现

- React / Vite / Lucide 界面，使用根目录 `DESGIN.md` 的白色、黑灰、胶囊控件与无阴影视觉。
- 用途 → 主考范围 → 已学边界与显式前提 → 题量分值 → 教学目标 → 确认。默认特殊前提不选；初中前置运算作为基础依赖保留。
- 默认教学目标为“先按范围组卷”；设置目标时默认“尽量满足”。选择“必须满足”会明确说明当前目标证据缺失造成的阻断，不自动降级。
- AI SDK 经 `LlmGateway` 整理自然语言，返回白名单选择、数字、文本和提示组件；schema 与业务目录校验通过后展示。建议不改写需求，显式采纳才更新；改动影响的步骤需重新确认。
- 模型未配置、失败、格式拒绝、取消与超时有可见状态，点击流程仍可用。需求会话、已提交原话与确认快照可以恢复。
- NestJS 单服务由 Express middleware 承载既有 handler，保留组卷业务模块。尚未逐路由整理成 Nest Controller/Service。
- SQLite 保存需求、模型审计、草稿内蓝图、修订与操作记录、不可变成卷、反馈及输出清单。素材和 PDF 保持文件存储；题库与待复核分析仍从版本化材料读取。

## 验证

`npm test`：125 项通过；`npm run build`：服务端 TypeScript 检查与 Vite 生产构建通过。新增检查覆盖真实题库合同、受控建议采纳、会话修订与操作幂等、模型失败、SDK transport、严格格式与业务纠错、SQLite 迁移/重启/跨连接 CAS、成卷不可变及 Nest HTTP 合同。

浏览器使用本机 Playwright：当前未安装技能要求的 Browser 插件，因此使用其规定的 Playwright 回退。隔离 Nest + SQLite 服务上验证了桌面 1440px 与手机 390px：六步点击、自定义 4 单选 + 2 填空 + 1 解答／70 分／35 分钟、范围和前提、刷新恢复、非零任务供给、必须目标证据阻断、草稿与成卷历史。浏览器错误为零，手机无整页横向溢出。

真实模型联调沿用经用户授权的旧 Tutor 服务。DeepSeek Flash 已成功返回受控建议，验证采纳前需求不变；供应商不支持原生 JSON Schema，因此采用 JSON object + 完整 schema 提示 + 严格本地校验。另一次浏览器调用发生格式拒绝，已证实没有改写条件；同输入诊断成功，原错误未复现，不能断言具体失败字段。已补充格式引导和至多一次严格纠错，两次尝试共享 60 秒期限，记录各次耗时与累计用量；网络、鉴权、超时和取消不重试。

随后发现一次 schema 通过而业务目录/组件校验拒绝的情况；已将业务 validator 纳入同一纠错预算，并收紧组件判别联合，只有两类校验都通过才记录成功。最终真实浏览器调用约 5 秒通过，3124 tokens，返回 7 个受控组件：采纳前摘要不变，手工将建议的 4 道单选改为 5 道后采纳，得到 7 题／60 分／30 分钟，刷新后原话和条件恢复，浏览器错误为零。该次建议也收窄了已学边界，说明语义理解仍需教师分别核对主考范围与解题边界，结构校验通过不等于教学判断正确。

停止隔离服务后重新创建 Nest 应用，恢复了已采纳条件、教师原话和真实调用审计，确认恢复依赖 SQLite 持久化而非进程内存。最终主服务历史再次与迁移前基线比对一致。

本地 4318 已切换 Nest + SQLite。迁移前停止旧服务并完整备份 `.tutor/`；12 个旧 JSON 业务对象导入成功，6 个草稿、2 个成卷与迁移前 API 内容逐项深比较完全一致，4 个输出清单保留。原文件未删除，数据库和 `.env` 均已忽略，不提交 Git。

设计对照使用概念图和实际桌面、移动截图：标题与辅助文案一致，左工作区/右摘要关系一致，黑白层级和描边图标一致，胶囊控件与留白一致。实际实现把概念图同时展示的用途和范围拆成逐步确认，并增加步骤导航，以降低单页输入负担；移动端摘要下移，选择胶囊单列排列。

## 尚未交付

- 四维题目目标支持证据尚未适配到选题。LLM 建议与题目支持证据分开；“尽量满足”不计为已证实覆盖，“必须满足”缺少证据会留空。
- 当前模型整理展示状态和最终结构化建议，尚未逐 token 流式渲染，也未实现开放式多轮聊天或任意组件生成。
- 当前需求并发控制面向单服务进程，多 worker 部署前需扩展跨进程会话 CAS。
- 题库仍以集合专项为主，不能据此宣称全高中范围可组卷；教学目标有效性、教师完成时间和实际采用意愿仍需真实试用。

## 本机试用

打开 `http://127.0.0.1:4318`，刷新后从点选需求开始，也可以输入原话点击“整理需求”。先检查并采纳 AI 建议，再逐步确认进入蓝图。历史入口位于左侧。模型配置更改后重启服务；备份先停止服务，再复制整个 `.tutor/` 及其引用素材。

## 2026-10-11：真实供给参与 AI 蓝图规划

需求确认后默认调用 `/api/blueprint/plan`，将已确认条件、任务目录、逐任务合格候选及重复组交给模型。点选默认保持 10 题与 100 分、允许建议题型配比；固定模式保留各题型数量。模型输出通过严格结构、业务约束和真实供给核查，教师确认后才选题并保存草稿。供给缺口可改善时反馈给模型修正，最多一次；不可改善或必须目标缺少证据时保留缺口，不能降级要求。失败不会自动切换预设。

真实 DeepSeek Flash 浏览器联调约 3.8 秒返回 9 道单选、1 道填空，各 10 分；候选去重容量为 10/10，确认后实际选满 10 题／100 分。确认前无草稿写入，确认后仅保存专用测试草稿。原试用草稿保持修订 7、10 题／98 分。此前一次真实调用的两次输出均总分不符，明确拒绝且未保存；随后补充实际总分、差值反馈和已核验整数分值参考，最终调用通过，代码未修正模型分值。该次成功证明链路可用，不代表模型稳定通过率或教学有效性。

156 项测试通过，TypeScript 检查与 Vite 生产构建通过。桌面 1440px、手机 390px 的真实浏览器流程、来源与规划理由、教师确认保存通过，无页面异常或整页横向溢出。另以独立浏览器请求拦截验证取消后条件保留、新请求结果不被迟到旧响应覆盖、失败后修改需求恢复、必须目标不可直接取消关联；这些边界测试没有额外调用模型或保存草稿。服务端检查断连取消、显式规则回退、固定配比、一次修正和编辑后必须目标保护。

蓝图规划使用 LLM；候选是否符合条件、去重与最终选题继续由规则执行。能力、素养与认知支持证据仍待适配复核，实际难度仍未知。

## 2026-10-11：按需确认知识与方法

已学边界步骤移除默认全量工具选项，改为“本次可使用的知识与方法”。`suggest_methods` 动作将本次范围内、版本一致且高中章节依赖符合已学边界的完整解法证据交给 LLM，提出少量相关额外项与用途说明；服务端限定建议只能修改额外方法许可，不得改变主考范围、已学内容或其他需求。原许可保留，范围或许可改变会清除过时建议，同一请求改变其他条件并采纳也会拒绝。完整手工表单仍可编辑已登记方法。

真实 DeepSeek Flash 调用约 1.9 秒通过，提出韦达定理、二次方程相关方法。浏览器验证生成时许可仍为空，显式采纳后写入这两项，主考范围和已学内容保持，刷新恢复成功；没有创建或修改草稿。桌面 1440px、手机 390px 无页面异常或整页横向溢出。164 项测试通过，生产构建和 TypeScript 检查通过，覆盖动态依赖、未知及无关项目拒绝、越权建议、取消、原子采纳和旧建议失效。

## 2026-10-11：单输入框快速入口

范围树和用途按钮放在同一个需求输入框上方；规模、已学例外、方法许可及手动表单入口默认折叠。选择范围后可直接发送，也可输入自然语言；发送后进入目标整理、需求确认、AI 蓝图规划。LLM 可提取文字中的题数、总分、时长，教师手动设置的规模优先，可显式解除手动锁定。点选范围和用途不由模型改写。

真实 DeepSeek Flash 浏览器联调验证“8 道集合题，80 分，30 分钟，辨析概念和包含关系”：采纳前保持为待确认建议，确认后蓝图显示 8 题／80 分／30 分钟，建议 5 道单选、3 道填空，去重供给上界 8/8。本次止于蓝图确认前，没有保存新草稿；原试用草稿仍为修订 7。该结果仅验证需求传递与规划链路，不代表教学质量已经验证。

浏览器检查范围父子勾选、空范围阻止发送、用途切换、Shift+Enter 换行、Enter 发送、修改恢复、停止后保留原话及刷新恢复。取消后回到输入状态，旧建议不可采纳；同会话读取等待在途事务结束，防止读到取消前状态。桌面和 390px 手机无整页横向溢出，本次浏览器错误与警告为空。192 项测试通过，TypeScript 检查与 Vite 生产构建通过。当前范围树仅提供已接入的集合章节。
