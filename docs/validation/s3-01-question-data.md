- 日期：2026-10-10。
- 当前交付：50 单元台账；18 个优先题目包已结构化、核对来源并就绪，其余 32 题待整理。018 采用用户确认的补明条件版本；不能写成 50 题全部可自动选用。
- 本文记录材料与读取实现；尚未实现组卷界面、自动选题、打印和真实使用验证。

## 最小实现

采用版本化 JSON 和 Node.js 原生文件读取，无数据库、网络请求或第三方运行依赖。题量只有 50，先证明能读取真实内容，再按实际需要扩展存储。

| 文件 | 用途 |
| --- | --- |
| `data/question-bank/sources.json` | 两份归档 PDF 的身份、路径、SHA-256 和物理页数 |
| `data/question-bank/ledger.json` | 全部 50 单元的审计 ID → 本地稳定 ID、状态、位置、教师资料存在性、内容问题和待办 |
| `data/question-bank/questions/*.json` | 优先 18 题的独立学生题面、教师资料、适配依据、版本与逐题核查记录 |
| `data/question-bank/course-context.json` | S2-01 采用的章节、基础依赖、显式前提及证据边界；不是下一次任务的自动确认 |
| `src/question-bank/reader.mjs` | 本地题目读取及校验 |
| `scripts/question-bank.mjs` | 命令行入口 |

`tutor-set-001` 等本地身份显式对应 `SET-SRC-001`，不冒称历史题库 ID。两 PDF 对应同一批 50 个父题，不计为 100；两道解答题分别保留父题和 `p1`、`p2`，不拆成四题。

学生结构只存 `stem`、`options`、`parts`、`assets`。教师结构分别存原卷结论 `source`、整理解答 `source_adapted`、标杆建议评分引用 `proposed`。建议评分注明适用上下文，不给题目设固定分值。原 PDF 不回写。

## 版本和读取结果

学生内容和教师资料分别使用递归排序对象键、保留数组顺序的紧凑 UTF-8 JSON 计算 SHA-256，完整摘要随包保存；短摘要构成 `content-…`、`teacher-…` 版本。核查记录与解法依据同时绑定这两个版本。读取时核对摘要及绑定，指定版本不符不能回退。

读取函数返回结构化结果，区分：

| 结果 | 含义 |
| --- | --- |
| `not_found` | 台账没有该身份 |
| `not_ready` | 身份存在，但仍待整理或存在未解决内容问题 |
| `version_not_found` | 请求的内容或教师资料版本不匹配 |
| `read_error` | 文件缺失、JSON 损坏或无法读取 |
| `integrity_error` | 摘要、版本绑定、来源位置或必要素材校验不通过 |

常规读取校验实际归档 PDF 摘要与引用页码；素材若存在须校验本地路径及摘要。学生读取只返回身份、题型、内容版本和学生内容，避免把教师答案、解法证据或核查笔记带入学生载荷。缺教师资料本身不构成学生题面自动禁用条件。

```powershell
npm run bank:list
npm run bank:get -- tutor-set-001 --student
npm run bank:get -- tutor-set-041
npm run bank:get -- tutor-set-050
# 用上一条实际返回的版本替换省略号
npm run bank:get -- tutor-set-041 --version content-…
npm run bank:check
npm test
```

失败返回非零退出状态。`check` 只验证就绪题的实际可读性，同时报告台账全部数量；待处理题不是一次读取故障，也不是合格候选。

## 来源核查与差异

本轮重新计算两份 PDF 摘要，与 [归档记录](raw/README.md) 一致。材料核查先提取文本定位，再渲染相关页并逐页视觉核对题干、选项、上下标、集合符号、小问与教师资料归属；主代理另抽查 001、034、045 及完整复核 041、050。每题包记录实际来源页、规范化差异、核查结果及对应内容版本。摘要用于复现，不能替代这项内容核查。

优先集合：001、002、003、007、008、009、010、013、018、020、022、034、035、041、045、047、049、050。已核查题不含必须另存的图形；`assets: []` 表示这些题无必要图形，不代表其余 32 题已做素材检查。

- 001、002、007、008、013 所在“原卷版”也混有答案/解答；只整理题面，未沿用 OCR 混合块。
- 022 将正整数符号规范化并留痕；034 保留空集、含空集集合等原选项，不声称与标杆 035 的每个细项等价。
- 041 保留最高次项系数为零的讨论；050 保留两个区间的开闭端点和跨页解答。

- 030 的解析措辞问题、032 的题面与解析对象冲突、038 的边界及证明疑点在台账分别保留。没有靠旧清单的 `within` 标签消除内容冲突。

### 018：原文差异与用户确认修订

教师版第 10 页、原卷版第 7 页原题为“若 $4\in\{a,a^2-12\}$，则 $a=$____”，原答案为 $-4$。原解答因互异性排除 $a=4$；但原文字面未说明集合有两个不同元素，$a=4$ 时集合为 $\{4,4\}=\{4\}$，仍含元素 4。

这是题意与评分的一致性问题，不是已学知识不足。用户于 2026-10-10 明确同意补充条件，结构化题面和标杆第 7 题现采用“集合含两个不同元素，且 4 属于该集合”。修订后排除只有一个元素的情形，答案仍为 $-4$，建议评分保持不变。原题全文、原结论、修订原因和用户确认记录保存在教师资料与核查差异中；原 PDF 不改，补充条件不冒充原 PDF 原文。该修订版本已纳入 18 题就绪集合。
