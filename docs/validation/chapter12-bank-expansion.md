# 第一、二章题库扩量与真实接口验证

日期：2026-10-12。范围为人教 A 版必修第一册第一章“集合与常用逻辑用语”、第二章“一元二次函数、方程和不等式”。真实调用当前配置的 `deepseek-official / deepseek-flash`，不是模型夹具。

## 交付与数量

从旧 Tutor 配置的题库进行只读查询，按实际知识点根 `M-K-01-100`、`M-K-01-200` 及其后代查到 515 个就绪投影，来源与内容完整性过滤后有 464 个候选。挑选 350 道不重复的题目，保留源题 ID、内容版本、来源试卷/出现位置、主考及依赖知识点和源内容哈希。

将它们分成 70 份、每份 5 题，通过当前 `POST /api/question-imports` 真实上传 Markdown；70/70 返回 HTTP 201，共拆出 350 道暂存题。没有直接将旧库题包伪装为当前模型的录入结果。随后通过管理员审核发布接口 `POST /api/question-imports/:importId/publish` 入 SQLite，保留原始上传、模型运行及独立发布审计。

新增可用题包括 258 道单选、29 道填空、26 道解答。其余 37 道保持待审、重复或批次阻断，没有为凑题量静默改题、补条件或解除门禁。跨章节主考映射可能重复计数，不能将小节数量相加当成独立题数。

## 难度由模型判断

313 道新增可用题的分档为：基础 122、常规 143、挑战 43、未知 5。每题保存 `difficultyBasis.method=llm_estimate`、依据和真实模型运行，`empirical=false`。不是学生作答实测，不生成虚假的难度系数。原 45 道种子题保持原来的未知分档。

组卷规划和候选比较现在收到模型分档及其判断依据；原先只入库却未传给组卷模型的问题已修复。整卷数值难度仍保持未知。教师界面的规划/选题摘要由最终题位及实际选中数量生成，模型原叙述留审计，避免声称尚未证明的教学目标已经达成。

## 来源与独立复核分开

逐题比对导入前后题干、选项、单选参考答案和小问结构；350 题学生端数学公式均经过 KaTeX 解析检查。17 个题干格式差异和 4 个小问合并差异单独检查，确认纯格式等价后才放行；数学符号或条件不清的题保留待审。

对 350 道源题以固定种子作分层随机抽样，独立验算 35 道：32 通过、1 错题、2 疑题。错题旧题号 6840 的函数复合换元错误，第二问应为 (4,6)，已隔离；8208 的求和指标、6132 的补集写法未明确，未发布。另隔离 6274 的关系符号改写、6364 的上方点标记问题，排除两对语义重复。

真实组卷逐题阅读又发现 5276 的单选 B/D 逻辑等价、6180 的补集全集 U 未明确、5821 的参考解析作差及符号判断错误，已从可用题中移出。5821 的单选答案正确，但教师解析错误仍不放行。没有把“来源保真”写成“所有答案已独立验算”。旧库不少参考答案本来由 AI 生成，保留 `legacyAnswerProvenance`，不标作官方答案。

## 解法依赖二次复查

实际组卷曾选入需要导数的 7428、需要指数函数的 6806：原标签漏掉后续知识，虽然程序按已存 ID 检查通过，数学上仍越出第二章已学范围。修复没有扩大教师边界，也没有假设未展示的初等替代解法。

对全部 322 道已发布题，再用当前 DeepSeek 阅读学生题面及完整教师解法，按五册真实教材的稳定小节 ID 标注依赖；证据引用必须逐字来自该题，并绑定学生/教师版本。316 道获得完整路径依赖，6 道保持未知；216 道补充了原来遗漏的依赖。先保留既有依赖，只作保守补充。失败批次逐题重试仍失败时保持未知，不接受无法定位的模型解释。

审计写在 `question_index.entries[].dependencyReview`，原发布记录及教师资料版本不改写。另以完整解法的显式操作检查导数、指数/对数、函数值域等漏项；这是补漏守门，不是完备知识分类器。初中根号有意义和平方根运算不据关键词误映射为高中指数。未知路径为空且题目保持待审；跨章题仍可在合适的已学范围下使用。只有已有完整路径证据足以证明时，才可以新增另一条初等解法，不要求所有题使用同一方法。

## 图片与表格

这批旧库候选先排除了明确带图片资产的题，没有用缺图题凑 300 道。对最终文本逐题检查图/表引用；四道“函数图象”文字描述有完整函数表达式，不依赖额外像素。资产列表为空不能证明旧库上游从未丢图，因此仍保留来源局限。

导入器现保留 DOCX 表格的行列/单元格、公式文本和图片占位；PDF 保留可识别表格并记录图片、Form 和矢量绘图。服务端关联来源页图表标记，即使模型漏掉占位，也会产生 `source_visual_unresolved` / `source_table_unresolved` 发布阻断。

**当前仍是文本模型录入，没有向 LLM 提供图片像素或实现扫描件 OCR。** 含图题不能声称已完整识别；DOCX 含图表时按整份文档保守待审，PDF 无线表格检测也有限制。真实图表接口实验另见 [图表导入验证](chapter12-visual-import.md)。

## 真实组卷与运行交付

扩量前及扩量后都通过独立 SQLite 的 Nest HTTP 服务，实际执行需求整理、采纳、确认、蓝图规划、AI 比较候选和保存草稿。结果、耗时及质量局限见 [扩量前基线](chapter12-assembly-baseline.md)、[扩量后复测](chapter12-assembly-post-expansion.md)。题位填满不代表教学目标已被证明满足，尤其含参空/非空分类的提高练习仍需关注。

审核库通过 `scripts/promote-reviewed-bank.mjs` 迁移到正在使用的 `.tutor/preview-4319/tutor.sqlite`；先 dry-run、备份，再事务复制题库、来源及审核记录。保留真实用户、登录会话、组卷历史和成卷快照，不迁移测试账户。历史草稿继续绑定原来的题面/教师版本；新建组卷使用扩量后的供给。

迁移及最终隔离后的核对：358 道 ready、367 份题包；1 个用户、1 个登录会话、5 份教学文档、33 个需求会话、19 条模型运行记录的逐表哈希与迁移前完全相同。SQLite 完整性为 `ok`，外键违例为 0。迁移备份位于原库旁的 `tutor.sqlite.before-reviewed-bank-2026-10-11T18-51-03-001Z-00bc611a.sqlite`；最后一道解析错题隔离前另备份 `tutor.sqlite.before-final-math-review.sqlite`。首页和 `/question-bank` 路由重启后均返回 200。

扩量暴露了题库列表性能瓶颈：隔离快照中首页约 15,439ms、基础难度筛选约 15,766ms。定向修复将 JSON 快照物化并按题目 ID/版本索引连接，把逐章节重复计数合为一次分组；同快照复测分别为 221ms、197ms，保持分页、版本校验和筛选语义。
