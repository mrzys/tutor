## 改动

- 新教程覆盖六项必需模型用途、PaddleOCR、来源转录、独立求解与分域核验、按实际问题核对及精确范围入库，原卷参考与AI答案解析分别说明。
- 从导入进入设置保留返回目的地及材料类型，显示已保存用途准备度与未保存草稿进度。批量绑定由教师明确选择已保存配置，保留有效思考覆盖、可选修订及通用模型，保存后生效。
- 选择文件仅本地暂存；发送卡使用实际文件后缀与已保存用途配置说明发送对象，点击开始才调用Rust。取消更换文件不改变原待发送文件的说明，失败保留文件。
- 三域状态与当前核对动作接入阅读页和底栏；默认定位未决域并展开相应材料，模型已有有效核验无需再逐域人工确认。Rust新增只读 `reviewableDomains`，缺少实际候选的域不提供必然失败的人工核对入口。局部保存响应按 `summary/question` 立即回显。
- 保留发布范围及未采用内容的未决事项；“原题及组卷信息”不发布AI答案解析，仍可能交付主考、路径与难度。
- 修复准确性资格响应将发布范围硬编码为完整成果的问题。范围从当前来源绑定的过程状态读取，局部保存、单题、整卷摘要及实际发布清单保持一致；不信任客户端已有的显示字段，不重复遍历整卷报告或资产来获取范围。
- 历史通过分页SQL统计已保存的待打开核对、重复、未采用及已发布状态。`readyCount` 明确保留未知；列表不读取原件、资产和核验凭据，实际发布资格仍由详情投影决定。
- 加载、空结果及查询失败分开；提高审核重要状态字号与操作命中区域，修复侧栏按钮遮挡返回记录及窄屏保存状态被旧列布局挤出视口。
