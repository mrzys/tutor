## 2. 标杆卷完整试题与标准答案（对照原卷）

### 一、单项选择题（共 6 小题，每小题 8 分，共 48 分）

#### 第 1 题（对应原卷解析版第 2 页 例1，目标预估难度：0.92）
**（2025 秋·南充校级期中）** 下列选项中，能够构成集合的是（　）\
A. 南充高中高 2024 级个子较高的学生\
B. 高中数学人教 A 版必修第一册中的难题\
C. 关于 $x$ 的方程 $x^2 - 1 = 0$ 的所有实根\
D. 无限接近于 $\pi$ 的所有实数\

- **【原卷答案】** C\
- **【原卷整理增补分析】** 根据集合中的元素满足的确定性特征即可求解。\
- **【原卷整理增补解答】** 解：对于 A，个子较高，不满足集合元素的确定性，故 A 错误；\
  对于 B，难题，不满足集合元素的确定性，故 B 错误；\
  对于 C，$x^2 - 1 = 0$ 的根为 $x = \pm 1$，故集合为 $\{-1, 1\}$，满足确定性，故 C 正确；\
  对于 D，无限接近于 $\pi$，不满足集合元素的确定性，故 D 错误。\
  故选：C。

#### 第 2 题（对应原卷解析版第 6 页 例2，目标预估难度：0.88）
**（2024·包河区校级学业考试）** 下列元素与集合的关系中，正确的是（　）\
A. $-3 \in \mathbb{N}^*$\
B. $\sqrt{5} \in \mathbb{R}$\
C. $\dfrac{1}{2} \in \mathbb{Z}$\
D. $0 \notin \mathbb{N}$\

- **【原卷答案】** B\
- **【原卷整理增补分析】** 根据元素与集合的关系依次判断选项即得。\
- **【原卷整理增补解答】** 解：选项 A，因 $-3$ 不是正整数，故 A 错误；\
  选项 B，$\sqrt{5}$ 是无理数，故必是实数，故 B 正确；\
  选项 C，$\dfrac{1}{2}$ 是分数，故不是整数，故 C 错误；\
  选项 D，$0$ 是自然数，故 D 错误。\
  故选：B。

#### 第 3 题（对应原卷解析版第 13 页 跟踪训练1，目标预估难度：0.82）
**（2025 春·唐县校级期中）** 集合 $\{x \in \mathbb{N}^* \mid x - 2 \le 1\}$ 用列举法表示为（　）\
A. $\{0, 1, 2, 3\}$\
B. $\{1, 2, 3\}$\
C. $\{0, 1, 2, 3, 4\}$\
D. $\{1, 2, 3, 4\}$\

- **【原卷答案】** B\
- **【原卷整理增补分析】** 解不等式 $x - 2 \le 1$ 可得 $x \le 3$，再由 $x \in \mathbb{N}^*$ 即可求得结果。\
- **【原卷整理增补解答】** 解：易知 $\{x \in \mathbb{N}^* \mid x - 2 \le 1\} = \{x \in \mathbb{N}^* \mid x \le 3\} = \{1, 2, 3\}$。\
  故选：B。

#### 第 4 题（对应原卷解析版第 20 页 例2，目标预估难度：0.80）
**（2025 秋·襄城区校级月考）** 已知集合 $M = \{-1, 0, 1\}$，$N = \{0, 1\}$，则（　）\
A. $M \subseteq N$\
B. $M \cap N = \varnothing$\
C. $N \subsetneqq M$\
D. $M = N$\

- **【原卷答案】** C\
- **【原卷整理增补分析】** 确定 $N$ 是 $M$ 的真子集，得到答案。\
- **【原卷整理增补解答】** 解：集合 $M = \{-1, 0, 1\}$，$N = \{0, 1\}$，则 $N$ 是 $M$ 的真子集，即 $N \subsetneqq M$。\
  故 AD 错误，C 正确；$M \cap N = \{0, 1\} \ne \varnothing$，B 错误。\
  故选：C。

#### 第 5 题（对应原卷解析版第 25 页 跟踪训练1，目标预估难度：0.75）
**（2025·安徽模拟）** 已知集合 $A = \{-1, 0, 1, 2, 3, 4, 5\}$，$B = \{x \mid |2x - 5| > 3\}$，则 $A \cap B =$（　）\
A. $\{-1, 0, 1, 4, 5\}$\
B. $\{-1, 0, 5\}$\
C. $\{2, 3\}$\
D. $\{5\}$\

- **【原卷答案】** B\
- **【原卷整理增补分析】** 首先求出集合 $B$ 中的不等式，求出 $x$ 的范围，然后根据交集的定义求出 $A \cap B$。\
- **【原卷整理增补解答】** 解：由 $|2x - 5| > 3$，得 $2x - 5 > 3$ 或 $2x - 5 < -3$，解得 $x > 4$ 或 $x < 1$。\
  所以集合 $B = \{x \mid x < 1 \text{ 或 } x > 4\} = (-\infty, 1) \cup (4, +\infty)$。\
  又集合 $A = \{-1, 0, 1, 2, 3, 4, 5\}$，\
  则 $A \cap B = \{-1, 0, 5\}$。\
  故选：B。

#### 第 6 题（对应原卷解析版第 25-26 页 跟踪训练3，目标预估难度：0.65）
**（2025 春·靖远县校级月考）** 已知集合 $A = \{x \mid x \le 2\}$，$B = \{x \mid x^2 - 2x - 3 \ge 0\}$，$C = \{x \mid x > a\}$，且 $A \cup (\complement_{\mathbb{R}} B) \cup C = \mathbb{R}$，则实数 $a$ 的取值范围为（　）\
A. $(-1, +\infty)$\
B. $(-\infty, -1]$\
C. $(-\infty, 3)$\
D. $(-\infty, 3]$\

- **【原卷答案】** C\
- **【原卷整理增补分析】** 解一元二次不等式求得 $B$，再由集合的交并补运算即可求得。\
- **【原卷整理增补解答】** 解：因为集合 $B = \{x \mid x^2 - 2x - 3 \ge 0\} = \{x \mid (x - 3)(x + 1) \ge 0\} = \{x \mid x \ge 3 \text{ 或 } x \le -1\}$，\
  所以 $\complement_{\mathbb{R}} B = \{x \mid -1 < x < 3\}$。\
  又因为集合 $A = \{x \mid x \le 2\}$，所以 $A \cup (\complement_{\mathbb{R}} B) = \{x \mid x < 3\}$。\
  因为集合 $C = \{x \mid x > a\}$，且 $A \cup (\complement_{\mathbb{R}} B) \cup C = \mathbb{R}$，所以 $a < 3$（若 $a \ge 3$ 则元素 $3$ 无法被覆盖）。\
  所以实数 $a$ 的取值范围为 $(-\infty, 3)$。\
  故选：C。

### 二、填空题（共 2 小题，每小题 10 分，共 20 分）

#### 第 7 题（对应原卷解析版第 10 页 跟踪训练4，目标预估难度：0.70）
**（2025 秋·水城区月考）** 若 $4 \in \{a, a^2 - 12\}$，则 $a = $ ________。\

- **【原卷答案】** $-4$\
- **【原卷整理增补分析】** 利用元素与集合的关系和集合中元素的互异性求解。\
- **【原卷整理增补解答】** 解：若 $4 \in \{a, a^2 - 12\}$，则 $a = 4$ 或 $a^2 - 12 = 4$。\
  解得 $a = 4$ 或 $a = -4$。\
  当 $a = 4$ 时，$a^2 - 12 = 4$，此时集合为 $\{4, 4\}$，不满足元素的互异性，舍去；\
  当 $a = -4$ 时，$a^2 - 12 = 4$，集合为 $\{-4, 4\}$，符合题意。\
  综上所述，$a = -4$。\
  故答案为：$-4$。

#### 第 8 题（对应原卷解析版第 26 页 跟踪训练5，目标预估难度：0.60）
**（2025·河北模拟）** 已知集合 $M = \{x \mid x < -1 \text{ 或 } x > 2\}$，$N = \{x \mid ax^2 - bx - 2 \le 0\}$，若 $M = \complement_{\mathbb{R}} N$，则 $a - b = $ ________。\

- **【原卷答案】** $0$\
- **【原卷整理增补分析】** 由题意可得 $-1$ 和 $2$ 是方程 $ax^2 - bx - 2 = 0$ 的两根，利用根与系数的关系求得 $a, b$，可求 $a - b$ 的值。\
- **【原卷整理增补解答】** 解：因为 $M = \complement_{\mathbb{R}} N$，所以 $\complement_{\mathbb{R}} M = N$。\
  因为 $M = \{x \mid x < -1 \text{ 或 } x > 2\}$，所以 $\complement_{\mathbb{R}} M = \{x \mid -1 \le x \le 2\}$。\
  所以 $-1$ 和 $2$ 是方程 $ax^2 - bx - 2 = 0$ 的两根，且开口向上（$a > 0$），\
  由韦达定理得：\
  $\begin{cases} -1 + 2 = \dfrac{b}{a} \\ -1 \times 2 = -\dfrac{2}{a} \end{cases}$，解得 $\begin{cases} a = 1 \\ b = 1 \end{cases}$。\
  所以 $a - b = 1 - 1 = 0$。\
  故答案为：$0$。

### 三、解答题（共 2 小题，共 32 分）

#### 第 9 题（对应原卷解析版第 26-27 页 跟踪训练6，满分 14 分，目标预估难度：0.65）
**（2025·柳州开学）** 已知全集为 $\mathbb{R}$，集合 $M = \{x \mid -4 < x < 4\}$，$N = \{x \mid 2m - 1 < x < 2m + 1\}$。\
(1) 当 $m = -2$ 时，求 $(\complement_{\mathbb{R}} M) \cap N$；（6分）\
(2) 若 $(\complement_{\mathbb{R}} M) \cap N = \varnothing$，求实数 $m$ 的取值范围。（8分）\

- **【原卷整理增补解答；本次建议分步评分】**\
  **解：**\
  (1) 因为集合 $M = \{x \mid -4 < x < 4\}$，\
  所以其补集 $\complement_{\mathbb{R}} M = \{x \mid x \le -4 \text{ 或 } x \ge 4\}$。（2分）\
  当 $m = -2$ 时，代入集合 $N$ 的不等式得：\
  $N = \{x \mid 2(-2) - 1 < x < 2(-2) + 1\} = \{x \mid -5 < x < -3\}$。（2分）\
  所以 $(\complement_{\mathbb{R}} M) \cap N = \{x \mid -5 < x \le -4\}$（写为区间 $(-5, -4]$ 同样给分）。（2分，本小问共 6分）\

  (2) 因为 $(\complement_{\mathbb{R}} M) \cap N = \varnothing$，且集合 $N = \{x \mid 2m - 1 < x < 2m + 1\} \ne \varnothing$（区间长度恒为 2），（2分）\
  所以集合 $N$ 必须完全包含在集合 $M$ 内部，即 $N \subseteq M$。（2分）\
  由 $M = \{x \mid -4 < x < 4\}$，得关于参数 $m$ 的不等式组：\
  $\begin{cases} 2m - 1 \ge -4 \\ 2m + 1 \le 4 \end{cases}$（2分）\
  解得：\
  $\begin{cases} 2m \ge -3 \implies m \ge -\dfrac{3}{2} \\ 2m \le 3 \implies m \le \dfrac{3}{2} \end{cases}$\
  所以实数 $m$ 的取值范围为 $\left[-\dfrac{3}{2}, \dfrac{3}{2}\right]$（写为 $\left\{m \;\middle|\; -\dfrac{3}{2} \le m \le \dfrac{3}{2}\right\}$ 同样给分）。（2分，本小问共 8分，全题满分 14分）

#### 第 10 题（对应原卷解析版第 22 页 跟踪训练5，满分 18 分，目标预估难度：0.48）
**（2025 秋·湖北期中）** 设集合 $A = \{x \mid ax^2 - (a+1)x + 1 = 0, a \in \mathbb{R}\}$，$B = \{x \mid x^2 - 5x + 4 = 0\}$。\
(1) 若 $A \cup B = B$，求实数 $a$ 的取值；（8分）\
(2) 记 $C = A \cup B$，若集合 $C$ 的非空真子集有 6 个，求实数 $a$ 的取值范围。（10分）\

- **【原卷整理增补解答；本次建议分步评分】**\
  **解：**\
  (1) 解集合 $B$ 的方程 $x^2 - 5x + 4 = 0$，因式分解得 $(x - 1)(x - 4) = 0$，解得 $x = 1$ 或 $x = 4$，\
  所以集合 $B = \{1, 4\}$。（2分）\
  对集合 $A$ 中的方程 $ax^2 - (a+1)x + 1 = 0$，十字相乘因式分解得 $(ax - 1)(x - 1) = 0$。（1分）\
  因为 $A \cup B = B$，所以等价于 $A \subseteq B$。（1分）\
  下面对参数 $a$ 的取值进行分类讨论：\
  **① 当 $a = 0$ 时**：原方程退化为一元一次方程 $-x + 1 = 0$，解得 $x = 1$，此时 $A = \{1\}$。\
  显然 $A = \{1\} \subseteq B = \{1, 4\}$，符合题意；（2分，**易错踩分点**：遗漏 $a=0$ 扣 2分）\
  **② 当 $a \ne 0$ 时**：方程的两个根为 $x = 1$ 或 $x = \dfrac{1}{a}$。\
  - 若 $a = 1$，两根重合，此时 $A = \{1\} \subseteq B$，符合题意；（1分）\
  - 若 $a \ne 1$，此时集合 $A = \left\{1, \dfrac{1}{a}\right\}$。因为 $A \subseteq B = \{1, 4\}$，所以必有 $\dfrac{1}{a} = 4$，解得 $a = \dfrac{1}{4}$。（1分）\
  综合 ①、②，实数 $a$ 的取值为 $a = 0$ 或 $a = 1$ 或 $a = \dfrac{1}{4}$。（本小问共 8分）\

  (2) 设集合 $C$ 中含有 $n$ 个元素，其子集个数为 $2^n$ 个，\
  则其非空真子集的个数为 $2^n - 2$ 个。（2分）\
  由题意可得 $2^n - 2 = 6$，解得 $2^n = 8 \implies n = 3$，\
  即集合 $C = A \cup B$ 中恰有 3 个不同的元素。（2分）\
  又已知集合 $B = \{1, 4\}$ 已有 2 个确定元素：\
  由 (1) 知，当 $a = 0$ 或 $a = 1$ 时，$A = \{1\}$，此时 $C = A \cup B = \{1, 4\}$ 只有 2 个元素，不合题意；（2分）\
  当 $a \ne 0$ 且 $a \ne 1$ 时，$A = \left\{1, \dfrac{1}{a}\right\}$，此时 $C = A \cup B = \left\{1, 4, \dfrac{1}{a}\right\}$。（1分）\
  要使集合 $C$ 恰有 3 个元素，根据集合中元素的互异性，必有 $\dfrac{1}{a} \ne 1$ 且 $\dfrac{1}{a} \ne 4$，（2分）\
  即 $a \ne 1$ 且 $a \ne \dfrac{1}{4}$。\
  综上所述，实数 $a$ 的取值范围为 $\left\{a \;\middle|\; a \ne 0 \text{ 且 } a \ne 1 \text{ 且 } a \ne \dfrac{1}{4}\right\}$。（1分，本小问共 10分，全题满分 18分）
