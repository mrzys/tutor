# S2-04：ADR-0002 采纳与开发移交

- 日期：2026-10-10。
- 结论：采纳 [ADR-0002：题库与蓝图](../adr/0002-question-bank-blueprint.md)，以当前范围启动 MVP 开发准备。
- 授权依据：用户确认第一轮 review 的处理取舍，讨论了默认赋分，并明确要求进入 S2-04。采纳记录不代表实际组卷、打印或教学效果已验证。
- 复核：Codex 对照 ADR-0001、S2-01、S2-02 和真实样例检查，未发现阻碍当前最小实现的关键设计矛盾。

## 本轮确认的取舍

| 事项 | 采用的原则 |
| --- | --- |
| 题库与蓝图 | 整理真实题目，蓝图表达选题目标，草稿记录实际选择；不预置标杆题目 ID 作为检索答案 |
| 已学边界 | 采用本次确认的知识与明确依赖，完整允许解法有证据才计为符合；未知和内容冲突如实展示 |
| 供给不足 | 初始无合格题留空，换题无合格题保留原题；不自动扩源或编题补位 |
| 分值 | 本次沿用 6×8+2×10+14+18 的默认安排，用户可改，实际合计与原 100 分基线的差异可见；不要求改分或删题后强行恢复 100 分 |
| 局部调整 | 保留无关题、锁定及独立成功项；用户仍能直接修改锁定题；新题不套用旧评分细则 |
| 交付 | 保存不可变成卷快照，两版同序同分；学生卷无答案，教师资料及评分来源可查，缺项不编造 |

第一轮评审的处理细节保留在[样例附件](blueprint-contract-walkthrough.md#第一轮评审处理记录)。不采纳“缺答案解析统一禁止选题”“无备选等于首次无题”“难度只能属于组卷”及无依据的替换比例阈值。

## 已知限制与落实任务

| 限制 | 后续处理 |
| --- | --- |
| 50 个来源题单元尚非可调用题库 | S3-01 建立全量台账，优先整理标杆 10 题及直接备选，共 18 题；其他项明确未就绪原因 |
| 原卷版有 11 个答案/解答混入单元 | S3-01 分离学生题面与教师资料，S3-04 核对实际两版输出 |
| 第 5–10 题位无完整目标直接备选 | S3-02/03 真实报告不足，保留现题；扩大来源由用户明确决定 |
| 030/032 有内容问题，038 边界及证明待核 | S3-01 保存问题及依据，不当作自动合格候选；用户选择的差异保留在摘要 |
| 难度及 45 分钟适用性未实测 | S3-02/03 保留预估与未知；S3-04 记录用户反馈，不冒充学生作答证据 |
| 尚无应用代码与实际用户运行结果 | 按[四项开发任务](../tasks/mvp-implementation.md)完成一条可运行的组卷路径，再实际验证 |
