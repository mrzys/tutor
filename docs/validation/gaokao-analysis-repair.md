## 核对方法与边界

逐页渲染本机保存的空白卷和解析卷，视觉核对题干、选项、各小问及答案，再修订独立分析。来源目录见 JSON 的 `provenance.rawPdfDirectory`。页码均为 PDF 物理页码，从 1 开始。每条 `sourceVerification` 保存两份 PDF 的 SHA-256 和实际页码；不能据此断言下载材料是官方发布版本。天津文件在封面明确标注“回忆版”，目录已保留这个身份。

本文件有 5 条试卷概览、10 条题目分析。`totalQuestionsAcrossPapers: 100` 只是五卷题数之和，不能解释为 100 题已经录入、逐题核对或已可选题。本轮不修改题库实体，不把高考分析自动转成就绪候选。帆船第6题依赖原图表，尚未建立独立图片资产。

`sourceVerification.status: evidence_verified` 仅表示题面、选项、设问和答案已与本地来源核对。顶层 `verificationStatus` 全部为 `pending_review`，教学目标支持仍需按新版目标细目独立复核。JSON 结构通过、源题核对通过，均不能自动把教学分析升级为已证实。

## 对教学分析的修正

- 帆船题已经给出视风、真风、船行风的合成规则。读图和已给关系下的运算有证据，自主提出该物理模型只得到部分支持。
- 全国Ⅰ卷第8题可以取共同参数为2、5、8，确认A、C、D可能后按单选排除B。不得声称构造复杂函数族、完整单调性分类是所有合理解法必需步骤。原目标定义来自错题面，须一并修订后复核。
- 全国Ⅰ卷第19题第2问允许反证法，也允许利用余弦解集直接证明。可提供反证训练机会，但不能证实每种合理作答都必须自主组织反证。其他求最值小问不完整支持“自主反证”目标。
- 全国Ⅱ卷第14题只要求填写数值；参考解法中的临界装配论证不能替代学生书面证明的作答要求。
- 全国Ⅱ卷第19题实际要求比较固定球数后领先至少2分的概率，不是比赛终局胜率。概率与独立性已经给定，删除马尔可夫链、无穷级数、大数定律等虚构必需知识；不凭“概率”关键词自动判定数据分析素养。
- 解答题另关联普通书面推导目标 `obj-written-derivation-01`；这些仍为待独立复核的支持判断，不继承过宽的反证标签。

## 数学检查

对全国Ⅱ卷第19题，记 `D_n=p_n−q_n`，修订解析给出两式：

$$D_{2m}-D_{2m+1}=\binom{2m}{m-1}(pq)^m(p-q)>0,$$

$$D_{2m+2}-D_{2m}=\binom{2m}{m}(pq)^m(p-q)>0.$$

另用精确有理数计算核对 `m=1…8`、`p=3/5,2/3,9/10` 共24组，两个差值等式及严格不等式均成立。球题核对半径`5/2`时勾股等式成立；第8题三个特值排列均成立。所有10条来源哈希及页码范围核对通过。这些检查补充书面推导，不能替代对题目活动和目标支持的复核。
