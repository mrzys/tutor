# 按需目标覆盖检查

2026-10-12 已发布至 https://tutor.mrzys.fun/。

## 修改

- `createDraft` 不再构建或调用覆盖复核 gateway。AI 候选比较继续按题型分批、最多两批并行；来源、范围、适配、版本校验和全卷去重组合保持执行。
- `/api/drafts/:id/coverage` 保留为教师显式操作；新草稿没有 `coverageReview`，不会伪装成已完成检查。
- 界面显示“目标覆盖检查 · 可选”和“AI 检查目标覆盖”，明确不阻塞查看、调整或保存。已有检查在题面或目标改变后仍按指纹失效。迟到的检查响应不得覆盖前端较新 revision 或已成卷状态。
- 导入说明强调对照原文件核对题面、答案、解析、公式，以及图片、表格对应关系。未解析图表阻断发布的现有门槛保持有效；未新增自动数学正确性认证。独立数学审核仍有抽样与来源比对的区分。
