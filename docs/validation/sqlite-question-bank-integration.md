# SQLite 题库与组卷工作台集成验证

日期：2026-10-12。

## 集成范围

- `codex/sqlite-question-bank-nav` 已合并到 `master`，合并提交 `6fd5196`；保留主分支当前题目排版与悬浮 AI 调整交互。
- Nest 服务启动时注册 SQLite。空数据库首次导入题库、教材目录、知识点映射、任务目录及课程上下文；已有数据库重启不覆盖现有数据。旧数据库只补齐缺失的配置快照。
- 题库目录、章节筛选、题型筛选、关键词查询、计数及分页从数据库读取；组卷候选与单题读取同样使用数据库中的版本和证据。
- 需求、蓝图基线、草稿修改、不可变成卷快照、反馈及 PDF 清单沿用 SQLite 存储，不再将运行时 JSON 文件作为组卷历史来源。
- JSON 材料保留为首次导入和离线审核输入。显式执行 `node scripts/sync-question-bank.mjs` 可同步材料；该操作会替换数据库题库及配置快照，运行前应停服并备份数据库。历史草稿与成卷不删除。

## UI 与 UX

使用 `ui-ux-pro-max` 复核，并遵循项目 `DESGIN.md` 的黑白、无阴影与紧凑排版约束。

- 教材目录支持键盘导航；窄屏改为可展开入口。
- 查询使用服务端分页和筛选；支持加载、重试、清除筛选及空结果状态。
- 组卷篮跨页、跨章节保留选择，刷新后恢复当前会话；提交携带选中题目的确切版本，由后端再次校验。
- 选项沿用已有的四列、两列、单列自适应排版；上传试卷入口收于题库工作区。
