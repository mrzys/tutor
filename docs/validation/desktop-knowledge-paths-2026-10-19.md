# 主考知识点与逐解法依赖验证

对应 [ADR-0006](../adr/0006-question-knowledge-paths.md)。以下全部为隔离目录中的模拟／开发回归，
不能用于声称真实教师采用或教学有效。本次未修改用户个人库和原网页库，未调用真实服务重标现有 358 道题。

## 实现

- 新合同为 `primaryKnowledgeUids`、`solutionPaths[].requiredKnowledgeUids`、`requiredPremises`、`basis`。
- 新版主考知识点与每条解法支撑知识点分别保存角色；同一支撑 UID 用于不同路径时分别保留路径身份。
- 模型标注直接关联；内容审核仍保留。缺标注或完整解法保持自动适配未知，不能退回旧章节条件放行。
- 显式知识点范围优先于章节；只标旧章节的题不能自动冒充符合显式知识点要求。
- 新版题数／知识点筛选只统计主考；教材位置为投影。前置与相关图谱不会自动扩展标签。
- 旧题、旧导入记录和冻结成卷保持兼容；新适配结果冻结本次主考 UID 和所选完整解法。
