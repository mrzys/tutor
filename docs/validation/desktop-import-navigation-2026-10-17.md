## 当前限制

- 每份文件最大 15MiB，提取文本最多 24 万字，模型返回 1–60 题；超限明确报错，不能截断后宣称完整。
- 扫描 PDF 没有文本时需先 OCR，当前不内置 OCR。
- 图片、绘图、Office 数学公式、DOCX 嵌套或合并表格等未保真提取时阻止相关题目发布；DOCX 以逻辑单页保守处理。普通 DOCX 表格和 UTF-8 LaTeX 文本已验证。
- 原文缺少答案或解析可以保持为空；不能由模型补写后冒充原卷参考资料。
- 题面审核入库与自动组卷适配分别确认；未确认主考范围、解法及依赖的题目不会静默进入自动选题。
- 模型回归使用本机模拟 HTTP 服务，验证调用与持久化流程，不代表真实供应商解析质量已评估。
