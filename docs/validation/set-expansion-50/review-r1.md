## 需要处理的题目

### 045：成员符号为上下文恢复

原卷集合 B 的定义显示为 `y□N`，现有转录写作 `y∈N`。主审用 PyMuPDF 与 Poppler 分别渲染，均显示缺损方框，并重新查看配套答案页：答案页只有第 1 题答案 D，没有可佐证缺损符号的推导。将其解释为自然数约束时，B={0,1,2,3}，与 A=(-3,3) 相交得 {0,1,2}，D 正确；但这只能验证恢复后的题目。

**处理：保持来源转写待确认。** 找到清晰原题，或由教师确认以修订题面保留，并明确记录改动；不能把恢复符号说成原页清晰可见。本轮未修改原转录。

### 020：独立解答通过，原答案仍未找到

A=(0,2)，B=[0,2]，并集为 [0,2]，对应 D。独立复核与已有 generated 答案提议一致。仍保持 generated 来源，不改成 source，也不宣称已经找到了原解析。

### 043：等价关系题需要保留零向量前提

独立结论为 AD。向量共线不满足一般向量集合上的传递性：取 a=(1,0)、b=(0,0)、c=(0,1)，a 与 b 共线、b 与 c 共线，而 a 与 c 不共线。若后续改成“非零向量”，答案会改变。原题没有排除零向量，本轮无须改题。
