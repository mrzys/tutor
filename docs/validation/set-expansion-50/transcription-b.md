## 保留的缺陷

- **028**：MuPDF与Poppler都显示题干关系符号乱码。忠实保留损坏位置及原答案B，不从答案倒推不等号，`sourceIssues=[stem_relation_glyphs_corrupted]`。
- **031**：C、D选项中关系符号在两种渲染器中均缺失。原答案A可见，但不能以答案A反推缺失选项，`sourceIssues=[option_relation_glyphs_missing]`。
- **046**：题面只写 $A=\{1,3,a^2\}$、$B=\{1,a+2\}$、$A\cap B=B$。按集合允许重复表示同一元素的字面解释，$a=-1,1,2$均成立，选项没有完整答案；原答案B（2）需要额外声明“A恰有三个不同元素”。本轮未擅自补条件，`sourceIssues=[unstated_distinct_elements_condition]`。
- **049**：B项原稿印为 $A\subseteq(A\,\mathrm{I}\,B)$，其中大写I未定义。其余选项和答案D可核查，但这不允许猜改该干扰项，`sourceIssues=[option_operator_undefined]`。

这4题应作为缺陷来源档案保存，由替补材料满足新增有效题数量。未设置可选标志，也未通过修改范围规则绕过缺陷。
